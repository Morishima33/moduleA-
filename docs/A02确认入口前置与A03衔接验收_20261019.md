# A02确认入口前置与A03衔接验收

用户反馈看到身份预览后仍无法选择整体通过。只读核查确认预览成功，但当前正式指针仍为候选，未提交标准化发布；界面将预览标为“标准化基因数”且将生成操作放在明细之后，造成完成状态误解。

## 改动

- 将身份处理确认区前置，例外直接展开，展示原名称、原蛋白编号、原始关系数、状态和归档依据。
- 明确标题“身份预览已完成”、数字表“预览可匹配基因数”，主要按钮为“确认处理并生成待复核结果”；重新核查置于默认折叠区。
- 右侧整体复核增加定位按钮；同版本预览存在时，阻断说明明确要求确认生成，不再重复要求已经完成的核查步骤。
- 原标准化入口所需八个固定公共参考文件先检查是否齐备，缺失时禁止提交并说明文件；后台继续调用原加载器核验指纹，不补造数据或自动切换版本。

## 验证与边界

23项隔离回归覆盖版本、身份例外、缺失参考包预检、只读及状态提示、接口与来源展示。隔离网页调用真实后台任务生成标准化结果，确认生成本身没有新增批准或A03；随后在合成研究网页明确提交A01/A02双复核，实际continue任务生成A03，手算交集为1，停在A03待复核，未生成A04/A05。

真实研究的四组COPD资料恢复及CALM1/P62158身份例外处理仍待用户明确决定，本轮仅修改程序与展示。不能将测试中的人工复核当作真实科研审批，不能为开放按钮而覆盖全排除决定。固定科学规则、旧运行、来源原件及正式大纲保持。核查证据存于仓库外开发与验收档案/audit_20261019/full_a02_handoff。
