# A04 新方案 STRING 置信度接续

本阶段把 `a04.required_score` 接入新方案的三处实际路径：STRING 网络请求的 `required_score`（方案小数乘1000）、网络边过滤、以及发布前复算。阈值等于边分数时保留，低于阈值时进入 `discarded_edges` 并记录方案阈值。来源包带有 `analysis_plan_id`、参数指纹和原始响应摘要。

实现位于 `src/science_modules/a04/plan_flow.py`，公开入口位于 `AnalysisPlanWorkflow.fetch_analysis_plan_a04_network` 和 `evaluate_analysis_plan_a04_network`。该入口只返回来源包或复算结果，不写入研究、不批准、不启动任务；后续生产任务接入时必须把同一来源包和方案指纹绑定到运行。

旧版 `ppi.py`、`ppi_flow.py`、`ppi_dispatch.py` 的 A04.1/A04.2 语义和固定900阈值保持不变。新路径没有继承旧身份补查授权回退，身份不明确时由复算结果阻断下游。
