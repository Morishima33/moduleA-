# A05排除应用后才展示KEGG（2026-10-11）

按用户要求修正：确认与应用展示排除清单之后，才显示KEGG图及两张前十表。拟排除提示、临时勾选、已保存未应用均不能当作已排除。

## 页面行为

- 未确认排除范围：只显示GO图表，KEGG位置提示先确认清单。
- 本地勾选改动：暂时隐藏旧KEGG图和表；恢复原选择可重新显示同一已应用结果。
- 后台处理中或确认已保存但未应用：不发送旧KEGG图表，提示查看任务；失败保留本地决定并允许重试。
- 新范围应用完成：从未排除显著通路中依次选取KEGG前十五、P值前十和Count前十；不足按实际数量，不放宽统计阈值。

## 统计和人工确认

只排除展示项，不重新运行ORA或BH；校正后P值、完整原始统计和历史结果继续保留。系统不代替用户选择无关疾病或签署A05结果。核验人、说明、对应勾选和“确认排除清单并生成图表”按钮仍用于明确提交。

新增只读接口字段kegg_ready、kegg_reason_zh；只控制展示，不改变A05.display.3科学统计和专业报告第19版。专业报告沿用“范围和版式均确认后才能生成”的门控。
