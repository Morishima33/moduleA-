# 成分身份回查与一次确认连续执行

用户要求修复名称定位失败和连接后未接续计算的问题，验证后上传开发分支。本轮不替用户签署任何独立复核，不改Vina参数、预测模型80/70/10门槛或原历史评分。

## 最终行为

- 原名称不能定位唯一PubChem CID时，按本研究成分的TCMSP稳定编号获取官方原页。页面中的MOL编号、原名称必须一致；完整InChIKey必须与PubChem一致。TCMSP未提供CID时，用完整InChIKey查唯一CID。随后下载原始PubChem三维，继续原有坐标身份核验。拒绝主页、错号、异构体冲突、非唯一结果，不生成坐标、不采用相似分子。失败注明名称检索、来源回查、化学身份、三维下载或坐标核验阶段。
- 新增`A06.compound_identity.1`来源解析标记，写入新连接包。旧一、二版来源代码保持；旧连接、历史授权及原件不回写。新运行归档新增解析模块及连续执行入口源码，支持回溯。
- 新增`automatic_start`接口、`a06_auto_start`任务和`A06.connect_run.1`接续。用户填写实际确认人、说明并明确勾选后，一次启动连接/补齐、准备、质控、评分和出图；没有连接时也能提交这一次明确确认。连接完成不再停第二次确认。仅连接按钮明确标为“不计算”，不作为执行授权。
- 连接前及计算前均核对同研究、已批准范围、父版本、当前结果及连接版本；参考选择按实际新连接重验。输入变化或来源任务未完成时停止。已有合格原件仅在同研究同批准指纹下复用，失败项再补查。取消沿用原自动批次失败留档，不假造批准。历史和回收站仍只读。
- 页面区分“仅连接”“尚待执行确认”和“已确认连续任务运行中”。新任务确认框默认不勾选，打开网页不产生写请求。旧自动接口保留兼容。
