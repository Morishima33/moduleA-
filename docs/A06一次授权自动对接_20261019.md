# A06 一次授权自动对接

版本：A06.automatic.1。授权来源为用户要求“连接完毕，我确认你直接算”，随后明确“修改”。本次实施程序和隔离验收，不替用户提交当前研究的执行授权或启动真实对接。

## 页面操作

1. 在 A06 准备页点击“连接资料”。按当前已复核的成分、A/B受体名单连接官方原件；下载不等于开始评分。
2. 查看连接数量和集中异常，填写执行确认人及说明，勾选一次确认后开始计算。
3. 后台连续完成配体准备、受体准备、口袋与环境核查、对接、热图和明细。个别对象失败不填零，保留原因，其余继续。进度及取消入口沿用后台任务面板。
4. 完成后到 A06 独立复核结果。每个分数可查看实际输入构型、PDB和链、搜索盒、质控范围、参数、命令、姿势及原始文件索引。执行授权不等于结果批准。

原分步流程折叠保留。旧试算交接、原批准和历史页面继续使用原协议。当前新协议尚未接入冻结的第24版双报告模板，因此明确阻止生成不完整报告；本次没有修改报告模板或Word大纲。

## 固定自动策略及科学边界

- 上游绑定 A00/A01/A02/A03/A03_SELECT/A04 的当前批准、运行和结果指纹；不增加A05前置依赖。不借用其他研究的旧225组合授权或计算结果。
- 成分名称须唯一命中官方 PubChem CID，官方属性和实际来源三维的完整结构键、立体身份须一致。不自动生成新立体形态、质子化状态或互变异构体；名称有歧义时保留待处理。
- 受体须有唯一 HGNC/UniProt 人类蛋白身份、明确作者链和零报告序列差异。官方RCSB按分辨率排序检索前20个实体，沿官方返回顺序最多采用两个不同PDB候选；作者链稳定排序。原件多模型、构象冲突或不适合现有工具时保留异常。A/B仅表示候选分组，不冒充结构质量。
- 同研究同源、已经明确的共晶方案可作为连接候选，仍重新质控；没有可靠共晶依据的新结构采用两次一致的P2Rank首位口袋，仅作探索。不能把新检索到的任意小分子擅自当作可靠参考配体。
- 共晶严格质控沿用Top-1对称感知重原子RMSD≤2 Å；搜索盒内伴随组分、缺原子及口袋完整性沿用冻结规则，问题未解决则跳过。严格不足五个时不补主要名额。
- 固定 Vina 1.2.7，scoring=vina、exhaustiveness=8、num_modes=9、energy_range=3、seed=1、cpu=2。每组使用同一预定受体位点的真实Top-1；不重选姿势或用零代替失败。
- 发布时复查真实姿势、原子编号及类型、搜索盒、实际命令和二进制哈希；重算归档RMSD、预测口袋盒与原坐标环境。自动执行提高操作连续性，不能证明真实结合、体内疗效或跨受体可比分值。

## 文件、版本和故障管理

连接文件放在本研究 `raw/A06_automatic/<connection_id>/<attempt_id>/`；授权放在 `decisions/A06_automatic/`；计算及所有尝试放在 `runs/A06/<run_id>/automatic/`。原件、软件指纹、代码副本、质控证据、完整组合、姿势、日志、PNG及CSV均登记研究内文件索引并校验哈希。

重新连接、上游换版或重签批准后必须重新确认。重复请求内容不一致则拒绝；失败重试生成新run，不覆盖上次尝试。同研究写任务互斥；取消终止进程树，已有证据保留，不自动重跑。文件下载只接受本研究登记ID及索引，不接受路径。回收站和历史只读。

本机 `science_tools_root` 由服务器配置，浏览器不能指定工具、结构、名单或参数。固定依赖用 Python `-I -S` 隔离加载。当前原项目仅提供只读工具资产，原功能代码与研究均未修改。

## 验收范围

隔离虚构研究测试一次授权、版本冲突、重试、不可覆盖、下载指纹、动态2×3完整异常矩阵及不代签；原A06兼容与质控回归；桌面1500和手机390宽度验证默认不勾选、一次请求和分数溯源。实际COPD计算和结果有效性尚未验收，须在用户网页授权后的真实任务中核查。

详细测试、截图、当前研究只读证明和上传证据放在重构根的“开发与验收档案/audit_20261019/a06_automatic_docking”。
