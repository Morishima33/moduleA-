# A06 两遍方案初步草案与进度保存 v7

## 页面怎么用
固定入口为重构根目录“打开重构核查页.cmd”，进入当前研究A06准备。
- 页面顶部“保存核查草案”：未填完也可保存，刷新后恢复内容及合法逐项勾选，不要求先勾满17项。
- 结构及成分弹窗“暂存此项”：直接保留未完成输入；“校验并更新草案”只在字段齐全后更新页面，后续仍需保存。
- “全选全部可确认项”只选字段已齐全的受体，NA项单项确认；全选不自动保存。
- “保存并确认方案”仍要求完整受体、成分处理、稳定任务包编号、核验人、依据和整体确认。刷新不会自动勾选整体确认。
“0/17”是已核对数量，不是运行进度。当前没有后台结构准备或对接任务，等待不会补齐资料。

## 草案与确认边界
逐项研究方案仅保存在本地研究的独立决策文件中，A06页面可展开查看身份、结构域、参考配体定位、既有失败、补救与缺口；研究明细不上传GitHub。未知替代构象没有资料时保持空白，不默认“无”。短肽、突变、其他蛋白的配体或共价参考不因分辨率高而自动采用；必要复合物/辅因子环境未解决时继续待补。
所有口袋、重对接及AlphaFold 80/70/10规则保持。结构坐标、模型、P2Rank、重对接和Vina本轮均未获取或运行。已批准成分保留，缺来源三维不自动记成已失败或NA，也不生成本地三维。展示窗口、完整组合及冰蓝—莓果红规则保持。
