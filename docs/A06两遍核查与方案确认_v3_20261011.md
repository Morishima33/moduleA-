## 使用顺序
1. A03_SELECT页：核对当前A03成分，保存新版选择；在右侧“复核决定”独立确认。旧失效名单只供对照。
2. A06_PREP页：顶部核查成分/CID与来源三维资料，再逐项填写受体两遍结构方案。第一遍须共晶参考配体；第二遍填独立结构和补救依据。没有可用资料可单项标记本次无法计算并写明原因。
3. “全选本页可确认项／全选全部可确认项／全部取消”只改变勾选，不保存。字段校验失败或缺资料项不能全选；NA项需逐项确认。
4. 填任务包编号、核验人和依据，明确确认后点击“保存并确认方案”。保存追加版本，不等于结构质控通过或A06结果批准。真实计算继续等明确指示。

## 两遍科学边界
两遍沿用同一A/B名单。第一遍核验HGNC、UniProt、人类蛋白及链，实验结构和明确共晶参考配体，当前研究Top-1重对接RMSD≤2Å。第二遍只对第一遍未通过者执行：优先另一个实验结构；允许无共晶参考配体实验结构；最后为AlphaFold数据库已有模型，禁止运行AlphaFold模型。

有参考配体仍须RMSD≤2Å；无可靠参考配体用P2Rank首位口袋、两次预测一致、保留证据并独立人工确认，RMSD为不适用，标记探索。人工口袋确认须绑定所选结构和具体预测证据，填写方案不能代替这次确认。第一遍重对接失败结构不能换成预测口袋绕过失败，须另选独立结构。

AlphaFold项目探索阈值：目标UniProt及模型序列范围一致，口袋映射/原子完整；首位口袋平均pLDDT≥80，每残基≥70，不同口袋残基间双向PAE≤10Å。缺置信资料或必要辅因子/复合物环境未解决则待补资料。这些阈值是本项目约定，不是结合位点验证。

配体仅使用来源三维文件，不本地生成，不换异构体、电离形态。来源SDF按研究、成分、CID和来源版本独立归档；上传只表示文件收到，三维坐标及化学/立体身份仍需准备阶段核验。

严格受体不足5个时，主要五名单为空，不用探索对象补足。达到5个时沿原完整PPI次序取主要五，不按A/B标签优先。候选等级与结构质控分列。所有已确认成分×全部A/B受体都有记录，失败为NA并保留原因，不能保证都有有效评分。
