# A06十五成分核查与同批矩阵

本轮新增成分核查草案及矩阵展示规则，不启动结构获取、准备、重对接或Vina。研究具体名单与证据在本研究 `decisions/A06_compound_review/` 独立留存，不写死于源码或上传研究包。

## 页面怎么核查

1. 打开固定重构入口，在左侧选择 **A03主候选确认（仅对接分支）**。
2. 先看置顶的本轮拟入选名单，逐项核对名称、CID、药味来源、原A03名次、身份及来源三维状态。每行展开可看证据与补充入选理由。乙酸折叠区提供批量表／详情／官方身份对照与224条关系逐行追溯。乙酸来源冲突继续待补，不自动加入十五项。
3. **全选本轮可确认项并载入补充理由** 只改变未保存选择；身份或药味来源待补项禁选。三维资料缺失单独提示，名单确认不宣称已经准备完成。
4. 填写成分核验人、选择依据，并勾选明确身份确认，再点 **保存新版成分选择（待独立复核）**。前列默认候选保留原角色，超出原规则的对象逐项保存人工补充理由。
5. 保存完成后刷新，在 **复核决定** 独立确认名单。它不重复批准已确认的交集，也不自动运行对接。旧失效名单与结果默认折叠，不能作为当前摘要。

## 图表和科学边界

重点热图取已配置八成分与八受体，扩展表取十五成分与十五受体；完整十五成分与十七受体的255个拟定组合独立留存。A优先、组内完整网络Degree降序，展示截断并列按HGNC编号稳定排列。未展示对象仍保留完整明细，不改变A/B分组、科学排名或主要五严格受体规则。

两视图来自同一有效版本的Vina Top-1评分，单位kcal/mol，不另算一批。单蓝渐变中评分越负越深，NA灰色并保留原因。显示A/B与严格／探索质控；评分不直接证明结合活性或药效。没有本轮真实评分时显示 **待计算**，不填示例数值或沿用旧分值。

成分核查资料绑定研究、当前A00/A01/A03/A04运行和复核、A/B候选分组及原始文件指纹。新草案、换源、重签或原件变化阻断旧页面请求，不回退更早草案。保存选择时在同一研究写锁内再次检查，防止后台任务使用过期核查资料。身份核查不重写A01分组、不重新归属可疑靶点、不改已确认交集。

已有来源三维只做化学身份、立体结构键及坐标初核，后续准备仍需通过既定质控。真实准备、RMSD与Vina执行守卫继续关闭，不能用参数开启。
