# A06 参考证据资格复算基础层

本阶段新增隔离的资格复算函数，按固定成分和受体清单复核已明确选择的参考证据，保持失败原因和未选择受体，输出准备矩阵但不执行评分。参考成功项必须再次通过实际证据检查；研究、来源准备运行、当前准备运行、输入编号、输入指纹和参数不一致时拒绝。

调用方必须先从当前研究经过指纹验证的归档构造准备事实；此函数不能凭客户端传入的字符串证明资料同源。此阶段尚未接入 Workflow、后台任务或网页，也不开放正式复核和评分。历史研究与历史协议不修改。

新增内部只读入口 `plan_reference_context_v2.derive_current`：通过当前研究索引、输入登记、准备版本及参考决定读取归档，调用已有第二版或第三版科学校验器复验准备，核对参考请求、选择、数量与文件指纹，再调用资格复算。隔离测试覆盖第二版准备、第三版已明确确认的探索口袋、旧决定过期、决定文件被篡改及读取不改研究状态。非空成功参考的归档链也通过模拟科学结果验证；此入口仍未发布为用户接口，也未归档新的准备运行，真实非空成功参考与完整归档链的组合尚未验证。

在 Windows 参考 Python 环境中，对资格复算、参考证据和重对接运行 24 项隔离测试通过；另对旧参考绑定与口袋的扩展测试运行 36 项，其中 2 项因独立重构根尚未安装科学工具而跳过（扩展测试在最后两项防护加入前执行）。4LWE/FJ2 公开样本的已归档参考证据通过当前函数重验，成分状态为合成数据，不构成真实研究验收。新根的核查记录位于仓库外 `开发与验收档案/audit_20261028/a06_reference_qualification_v2/`。

增加归档上下文后，同一解释器运行 25 项相关测试全部通过；归档链测试使用空参考选择和合成隔离研究。

新增 `A06.plan_reference_preparation.2` 内部发布版本：明确请求后基于同研究原准备和参考决定复算，保存固定输入、结果表、逐件来源指纹和代码快照，独立校验器可从固定归档重算；不改变第一版校验器。保留人工审核及评分阻断。隔离测试覆盖空选择、第三版口袋结合模拟成功参考、结果篡改拒绝及重复请求；模拟参考不证明真实重对接。此版本目前仅供后台 Workflow 调用，尚未连接网页或任务入口。
