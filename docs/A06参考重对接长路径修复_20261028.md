# A06 参考重对接长路径修复

真实参考链路核查发现，新准备与参考核查的深层目录使受体路径达到278字符，Windows Vina 1.2.7无法打开输入；仅改成相对路径仍失败。同一原件和参数采用系统短文件名后，实际参考重对接成功。

新方案准备引擎对Windows长路径调用GetShortPathNameW，并确认短路径解析后仍是原文件；不复制、更换输入或修改科学参数。输出通过已存在父目录取得同位置短名。若系统未提供可用短名，仍阻断并报告原因。命令保留实际使用的参数，证据校验将文件参数解析后与本研究逐件核验的目标文件比较；旧绝对路径命令保持可读。

验证使用此前归档的官方4LWE/FJ2原件，重新实际执行Meeko准备、参考Vina重对接、参考证据复验及新版准备的隔离后台发布。Top-1 RMSD为0.636366125869256 Å；同研究参考通过数为1。上游网络和登记是合成工作流，测试成分均NA，两个固定组合保持NA，评分数为0，正式交接仍阻断。此结果证明参考准备和发布的技术链路，不代表真实疾病研究或正式组合评分完成。

相关29项测试通过，包括超过260字符的原件与待写输出路径对应关系。旧公开样本的历史绝对路径命令再次复验通过。故障日志、诊断、实际重算及后台发布记录保存于仓库外`开发与验收档案/audit_20261028/a06_reference_actual_chain/`，历史来源和失败记录保留。
