# A06受体补救展示与下载

本说明仅覆盖 `A06.system_rescue.1` 运行的网页与图表交付。准备、口袋、评分和人工复核规则由独立科学协议及原运行决定；展示不修改它们。

页面先列本轮尝试受体数、补救后准备可用数、沿用原有效评分数、本轮新增评分数和剩余NA/失败数。这些数字读取已归档摘要。固定成分条目与来源关系、独立化学结构分别解释，不能把同名条目合并为一个成分。

“焦点热图”初始显示至少有成功评分的成分与受体。两个选择器以及“显示成功对象”“显示完整范围”只控制本图显示，不保存新名单、不发起计算。下方完整矩阵始终保留本批全部成分记录×受体，包括整行、整列和单格NA。刷新仅重新读取原件。

名称取自本运行绑定的固定输入，不借用其他运行的候选名单或推测译名。同名条目在标签后加稳定短编号，悬停可查看完整身份。每个格子都可点击核对原始未舍入评分、严格/探索类别、原评分或本轮补救来源，以及NA/失败原文。只有结果附件索引中路径、长度与SHA一致的原件才显示证据下载；未提供链接时明确说明，不推断存在Top-1文件。

颜色只描述完整同批评分范围：更负为红、较不负为蓝；NA保持白底虚线和“NA”，不填零。焦点子图沿用完整矩阵色标。探索评分不等同严格验证，对接评分不能直接证明药效。

后台显式执行时生成以下独立附件，页面读取和选择操作均不会重新导出：

| 附件 | 内容 |
|---|---|
| A06_完整结合能热图.png / .svg | 完整固定矩阵；保留NA与同名身份 |
| A06_焦点结合能热图.png / .svg | 有成功评分对象的固定焦点视图；全无有效评分时不生成 |
| A06_完整评分明细.csv | 全部组合、原始评分精度、NA/失败原因及来源类别 |
| A06_补救展示.json | 与图表同源的展示数据和完整原始评分 |

下载通过标准运行附件链接逐件核验。历史运行读取自己的固定输入、评分及附件；新图不会覆盖旧评分或历史图。新A06结果仍须独立人工复核，本功能不生成或修改Word。
