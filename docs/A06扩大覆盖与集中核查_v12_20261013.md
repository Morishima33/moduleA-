# A06扩大受体覆盖与集中核查（v12，2026-10-13）

本轮执行用户确认的扩大覆盖方案。技术质控、用户采用范围、A06结果批准及批量计算授权分别记录；本轮不进行成分×受体批量评分。

## 核查与补救

- 17个A/B受体全部保留；第一遍严格核查，第二遍仅补救未通过对象，候选梯队不变。
- 参考配体保持Vina 1.2.7固定参数，实际Top-1对称校正重原子RMSD≤2 Å。失败原结构不能改成预测口袋绕过；独立替代结构另归档。
- 参考配体周围5 Å用于定位初筛。编号相邻不判损坏；无坐标片段需同一UniProt的完整实验对照、残基映射与空间拟合，未解决则待补。原件明确的非原生表达标签单独记录。
- 记录官方生物组装、必要蛋白伙伴和金属的保留依据。添加剂只有原件结晶条件明确支持时才移除；未知组分、参数化失败或环境不完整不放行。
- 无参考配体使用P2Rank首位口袋，两次一致并留存完整输出，按原位点相关结构域核查，用户集中确认用途。已有AlphaFold数据库模型执行80／70／10边界；不运行模型，不改取后续口袋凑数。

## 页面操作

在A06顶部点击“查看汇总并确认可用范围”。一个窗口展示全部受体、A/B、拟采用结构与位点、严格／探索类别及未解决原因；详细来源和两遍记录可折叠。

“全选全部可确认项”仅选择已有技术证据的对象；未解决项不可选。“保存草案”可保存未完成选择，刷新恢复。核对后填写核验人与依据，勾选窗口确认框，再点“确认本轮可用范围”。确认交后台留存，完成后显示“查看本轮已确认范围”；不会批准结果或启动批量计算。

至少五个已采用严格受体才满足主要五条件，仍按原PPI顺序选取。探索对象单独使用，不补足严格名额；失败组合保留NA和原因。后续批量计算需要新的明确授权与对应执行入口。
