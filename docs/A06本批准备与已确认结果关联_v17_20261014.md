# A06本批准备与已确认结果关联

前页A06_PREP当前展示“本批对接准备”，与已确认A06使用同一批十五成分、十五受体。状态为“准备范围已核查（扩展试算）”，沿用原试算核查及A06批准，不要求再次确认。

## 页面及核查来源

页面依次显示本批准备摘要、15受体准备表、成分准备资料、默认折叠的历史严格质控。受体列为受体、A/B梯队、实际结构、位点／搜索方式、准备修补、用途及证据；成分显示CID、原身份信息、来源三维与实际准备文件。

“查看核查来源”打开中文汇总，展示原核查人与时间、说明及已关联A06，可下载原始记录；“前往已确认A06结果”返回原结果。前页不重复热图、评分矩阵及保存表单。历史区不提供旧范围的勾选或保存；历史RMSD、失败及待补保持。

对历史复用且本批未重复登记来源的受体，按实际准备文件指纹回溯原准备包，再按目标、结构编号、UniProt及来源核查索引取得原件。该过程只补充只读关联，不改本批packet或旧元数据，不按名称猜测文件。

## 版本保护

- 独立协议为`A06.trial.preparation_link.1`，追加至研究的`decisions/A06_trial_preparation_link/`，由Workflow公开方法在写锁内留存。
- 关联绑定研究、A06运行及最新批准、试算及原核查、原准备指针、实际准备与来源文件指纹。已有同样关联时不重复产生版本。
- `current`、科研运行索引及人工`reviews`保持；旧A06_PREP不改为已批准，不更换A06/A07或重算评分。此记录不是新人工签名。
- Workflow视图生成`scope_confirmed`，导航、标题、待办统一使用。`approved`仍仅计正式批准，新增`completed`计已完成关口；有关联的研究分别显示两项数量。
- 关联不再有效时显示失效原因并隐藏当前十五项，不能继续显示已核查。无关联研究保留原流程；回收站及历史只读。
- 文件下载只接受当前研究索引中的`prep_link_ID.序号`，验证原件指纹；不接受任意路径。显式查询旧准备运行返回历史只读视图。
