# A06 来源原件核查与集中方案选择 v9

用户已明确授权“允许获取并核查资料，暂不计算”。本轮按已确认名单获取官方三维及实验结构原件，沿用原身份规则，不更换化学身份或自动准备结构。

## 页面怎么操作

双击重构根目录“打开重构核查页.cmd”，进入当前研究A06准备，点击标题后的“查看汇总与确认”。

1. 查看同一窗口内的构象及位点／探索路线说明，可点击“填写全部建议（仅草案）”一次填入可修改建议。
2. 不认可的条目可改选其他已有构象或“继续待补”。待补不会自动变NA，未完成内容仍可暂存。
3. 填实际核验人和简短依据，主动勾选整体核对，点击“一次确认完整方案”。服务端一次核验来源、字节版本与完整名单，未通过则列出缺口并保留输入。

一键建议不发起保存、不勾整体确认、不启动计算。构象建议A不表示其生物学上更优；所有来源仍须实际准备和质控，必要环境未解决时不得通过。完整方案确认、结构质控、真实计算授权及结果批准分别操作。刷新不恢复整体确认。

## 核查与留存边界

- 三维预核对比对已确认属性、当前官方属性及原件CID、完整结构键、分子式和坐标立体身份，不本地生成三维、不预测pH、不换异构体。
- 实验结构复用既有只读链身份、原子及未观测记录清点；同时检查实际序列差异和共价连接，不把摘要mutation_count为0当作序列无冲突。
- 冲突来源保留原件与原因，改用独立候选核查；短片段不得冒充完整折叠受体。未观测记录数量不是口袋质量判断，不自动删水、补缺失或决定辅因子环境。
- 新A06.source_review.1原件版本独立保存在研究raw及decisions中，指纹与现有来源、CID、目标链和候选绑定。旧原件、已批准运行及科学版本保持。
- 新来源核查版本使旧窗口、草案和完整方案不再作为当前确认；原件下载只能使用本研究登记的版本及文件键。
- 新上传三维未经本轮原件核查不能沿用旧预核对。没有实际评分时图表仍待计算，所有组合范围和已确认配色保持。
