# A06 核对入口即时打开 v10

## 本轮修正

“查看汇总与确认”只打开已经加载的核对窗口，不先发起重复核查请求；“填写全部建议（仅草案）”在窗口顶部，页面入口旁同步说明位置。即使预检接口暂不可用，仍可查看资料及填写本地选择。

保存期间在标题下显示进度，并阻止重复提交；当前已留存的完整方案显示“方案已确认并保存”。修改后仍需核对新方案，窗口不自动恢复整体确认勾选。

## 边界与大纲对应

沿用“资料核查→集中核对→方案留存→明确授权后计算”的已确认大纲。正式提交仍执行原有服务端完整性、来源与版本检查；打开窗口与一键建议不会保存、批准或启动计算。原科学规则、受体和成分名单、科研结果保持。

本轮只修改前端交互、重新构建页面，并增加隔离／真实只读浏览器回归；不修改接口或冻结科学内核。研究资料、测试截图和运行日志留在重构目录的独立核查区域，不上传 GitHub。

## 核验结果

修复前，模拟预检接口不可用能复现入口打不开；修复后隔离浏览器6项、真实只读页面4项检查通过，实际入口打开约0.1秒。隔离草案保存返回201，完整方案留存返回202；真实研究只打开、填写本地建议后刷新，3931个文件逐项校验不变。TypeScript与前端生产构建通过，浏览器无脚本错误，完成弹窗布局后窄屏无整页溢出。
