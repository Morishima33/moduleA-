# A06热图恢复与评分标记

用户于2026-10-13要求恢复此前热图配色，并在15×15表中给原始评分≤−8 kcal/mol的格子加“**”。

- 展示版本为A06.trial.display.2。恢复历史blue_v1配色：浅蓝#EFF6FF至深蓝#08519C，评分越负蓝色越深；NA灰色。8×8、Excel和专业版图件使用同一完整225格有效范围。
- 15×15网页及专业版表显示两位小数，并为符合条件的格子附“**”；8×8不加星。阈值根据未四舍五入的原始评分判断，例如−7.99999显示−8.00但不标星，−8.00000标星。
- 表注：“**：原始Vina评分≤−8 kcal/mol，仅为本表数值标记，不表示统计显著性。”
- Excel通过数字格式追加符号，单元格仍是完整精度数值；CSV继续保留原始数值供分析。不重算、不修改评分、不筛掉任何成分或受体。
- 新图件和专业版A06补充报告另存展示版本；网页默认只提供本版下载，旧配色、旧图件与核查记录保留。

代码位置：trial_presentation.py统一配色与阈值；trial_exports.py生成同批导出；modulea/api/trial_view.py提供颜色、标记及最新下载；DockingTrial.tsx展示；export_a06_trial.mjs保留Excel数值类型。
