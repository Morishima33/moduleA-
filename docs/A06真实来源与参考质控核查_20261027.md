# A06真实来源与参考质控核查

本阶段是公开样本的隔离科学验证及共晶证据适配，不新增研究评分入口、不写研究manifest或人工reviews。`plan_reference_evidence.py`只消费明确的受体、结构与参考配体稳定键，复用已冻结的身份、序列、CCD、Meeko和Vina内核；选择本身不能代替结构质控。

## 复验范围

- 从官方CCD与实验坐标重新生成参考SDF/PDBQT，并与实际输入文件比较。
- 从原mmCIF重新生成PDB、参考重原子包络及每侧5 Å外扩，复核盒参数。
- 重新核对实际Vina命令的输入、输出、搜索盒、scoring、exhaustiveness=8、num_modes=9、energy_range=3和seed=1。
- 从实际Top-1输出再次计算对称重原子RMSD，不换姿势、不沿用历史分值。
- 篡改RMSD、随机种子、盒外扩、参考稳定键或质控标签，五种情况均被拒绝。
- 原件、输出、运行配置、来源请求和SHA-256在仓库外保留；可变下载断点与不可变证据清单分开，离线复验不重新下载或运行Vina。
