# A06补救路线接续第二版

版本：A06.automatic.2。用户指出原全覆盖方案未接入新入口，并明确要求“修改”。本轮完成代码、隔离验证和网页更新；没有替用户确认当前研究执行，也没有对当前COPD资料联网补查或运行真实对接。

## 修复问题与页面操作

第一版新入口只检查官方前20个实体，并要求所有序列差异计数为零，构象并列即停止，没有完整接续旧方案的分页检索、替代结构和探索补救。第二版独立修复这些遗漏，旧版本科学行为、原件、运行和批准继续保留。

刷新A06准备页，旧连接会显示“请先补齐连接资料”。点击“补齐连接资料（复用合格原件，不计算对接）”，程序复用同研究、同上游批准且哈希一致的成功来源，仅补查未连接对象。连接成功只代表原件已取得，不代表结构质控通过。

补齐后查看新范围及剩余异常，再填写执行确认人、说明并一次授权。程序连续准备、补救、对接和出图；结果另在A06独立复核。旧确认不会自动升级为第二版确认。旧版请求只有显式声明原策略才按原策略验证，页面默认使用第二版。

## 补救顺序及边界

1. 官方来源暂时网络错误最多三次，逐次独立归档；404等永久错误不反复重试，网络失败不写成零命中。
2. 官方实验结构每页100项，直到找到可用候选或检索确实耗尽，不以20项为终点；重复页或提前空页明确报错。初次连接取得候选后停止额外下载；实际准备失败会继续独立候选。
3. 唯一HGNC/UniProt、人类来源、实际作者链及原坐标序列必须一致。按官方线性映射逐残基核查，实际匹配的片段可用于明确标记的探索；真实突变、未知映射、未核定的已解析标签或非标准残基不直接放行，不自动修复突变。
4. 替代构象必须覆盖全部替代原子，以总占有率选取；并列固定按字母排序并留证，仅作探索。不混合各构象凑齐原子，无完整一致构象则改用独立来源。
5. 明确共晶方案仍用原Top-1重对接RMSD≤2 Å及环境规则判定严格通过。其余沿原全覆盖试算的有限侧链准备路线，只补已解析残基侧链；原重原子坐标不变，不补主链、长环或未建模残基。准备失败继续独立结构。
6. 实验候选补救仍不适用时读取已发布AlphaFold模型及官方序列、pLDDT、PAE；不运行新模型、不拼接任意片段。每个采用区域平均pLDDT≥80、最小≥70、双向PAE最大≤10 Å，仅作探索。
7. 预测区域使用两次一致的完整预测表；预定的可映射区域在评分前冻结。无可映射口袋时沿原规则用30 Å盒、15 Å步长、外围5 Å分区。工具执行失败不解释为“没有口袋”。
8. 每个采用区域独立核查环境与缺失；需要保留的金属、辅因子或伙伴不能被蛋白单体准备静默丢弃。未解决主链/残基缺失不以侧链修补替代。
9. 同一受体全部成分使用同一结构和区域集合。各区域使用原固定Vina参数及真实Top-1，取有效区域最低值；部分区域失败明确记录。未得到评分保留NA或失败及原因，不填零、不凑严格名额。

“尽量全覆盖”不等于保证每个对象有可信评分，也不表示预测模型已验证真实结合位点。无可用来源、低置信度、工具或必要环境问题均可能留下NA。

## 归档和发布检查

新连接、执行授权和每次尝试使用新的ID，沿用本研究目录。补充检索、模型原文、序列、原构象、修补前后坐标、逐区域环境和置信度、Vina命令、原始姿势及失败输出均保留。发布时从实际原件重核序列、所选链和构象、修补重原子、预测表、区域集合、实际分数、命令和软件指纹；不只相信摘要中的通过标记。

工具位置只来自服务器的science_tools_root和science_repair_packages，不接受浏览器路径。固定修补环境是PDBFixer1.12.0/OpenMM8.4.0；固定Vina1.2.7及原参数不变。第一版模块和旧15×15协议保留，不能把旧病例授权或结构资料搬入本研究。

第二版尚未接入冻结的第24版双报告模板，因此继续明确阻止新协议生成不完整报告。本次未修改模板或Word大纲。

## 验证及其范围

隔离虚构数据覆盖：超过20项的分页、失败重试、重复/空页、实际片段序列与突变拒绝、构象并列、模型身份和PAE、替代结构到模型的接续、逐区域置信度、多区域取最低Top-1、旧策略保护、同研究复用、2×3完整异常矩阵、成功分数及篡改拒绝。固定修补工具另用虚构小蛋白实际验证正常输入、只补CB侧链及拒绝缺主链。

网页用Python实际托管，在1500/390宽度检查旧连接迁移提示、确认不预选及溯源入口；真实研究页面只读，核对新策略、原连接保留及manifest前后相同。实际COPD七项补查结果与评分尚未验证，须由用户在网页启动补齐并确认计算后核查。
