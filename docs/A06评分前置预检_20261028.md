# A06 新版评分前置预检

本次将新版准备的只读评分预检接入 Workflow、HTTP、网页和生产构建。它检查绑定资料，显示实际参数，不登记复核决定、不创建任务、不运行评分。

## 来源与行为

`POST /api/v1/studies/{sid}/analysis-plan/a06-scoring/validate` 仅接受 `expected_preparation_run_id`、`reviewer`、`note`、`confirmed:true`。拒绝额外参数、过期版本、回收站、损坏或跨研究来源。API 在不安装科学依赖的环境中可执行。

当前参考绑定版的配置只有绑定标记，不能作为 Vina 参数来源。预检沿固定输入找回 `A06.plan_preparation.2` 的实际配置，核对研究、登记索引、原结果、事实包、输入、方案和 SHA-256。返回来源运行、方案参数指纹、配置指纹和原搜索参数，同时核对固定组合、ready/NA 数及空评分。输入或上游已变化时列出阻断，检查期间研究版本变化则拒绝。

当前返回始终为 `read_only:true`、`allowed:false`、`execution_available:false`。即使资料完整，也不表示人工批准或获得执行授权。

## 网页操作

进入新版准备研究的 A06_PREP 页，在“正式评分闸门”内展开“检查评分前置条件（不启动计算）”。填写预检人和说明，主动勾选后提交；页面展示服务端返回的实际参数及阻断原因。首次不勾选，刷新或准备版本变化后清除旧结果。表单不保存科学决定。
