# A06 集中核对与一次确认 v8

按用户“继续，尽量让我确认一次，我确认的简化”实施。

## 使用方式

固定入口：重构根目录“打开重构核查页.cmd”，进入当前研究 A06 准备。标题下点击“查看汇总与确认”，同一窗口汇总成分、完整受体、全部组合、待补内容及明确无法计算项。

- 正常项目在窗口核对后，填写实际核验人与简短依据，主动勾选整体核对，点击“一次确认完整方案”。无需先逐行辅助勾选全部受体。
- 明确无法计算的受体或成分仍在该窗口逐项核对NA原因；缺失资料不自动改成NA，不降低科学要求。
- 资料未齐时同时列出结构、成分和任务配置缺口，完整确认关闭。“保存未完成草案”可保留进度，刷新恢复；不会再次要求用户批准已有名单。
- 官方来源、逐项编辑和辅助勾选默认折叠，必要时展开。修改或刷新后整体确认与NA确认不自动勾选。

## 边界与版本

确认资格由服务端使用既有A06.two_pass.plan.1完整校验生成，前端不推算科学通过。不改变A/B、两遍筛选、配体形态、独立补救、口袋确认、AlphaFold阈值或Vina参数。资料字段齐全只表示可确认方案，不表示结构质控完成。

方案确认、结构质控及最终结果批准分别留痕，真实资料获取、准备和计算仍按各自授权进行。原已确认模块、原项目、已有科研结果和正式Word大纲保持。研究的具体名单、官方查询响应、截图及过程资料留在仓库外独立核查目录，不上传GitHub。
