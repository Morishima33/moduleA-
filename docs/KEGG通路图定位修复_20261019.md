# KEGG通路图定位修复

用户反馈A05操作顺序处看不到通路图。只读核查确认当前IL-17和PI3K-Akt两个首位命中图已归档，图片接口均返回200且可解码；不是缺图或需要重新计算。

真实网页复现：点击第4步后，上方GO/KEGG图片首次解码使页面高度增长，通路图区域从屏幕内移到下方约2066像素；原导航还按整个大型图组居中，无法稳定定位标题。

仅修正第4步阅读定位：先定位标题，待前方及本组图片解码后再校正位置，并为固定顶栏保留88像素边距。用户滚动、触摸、按键、再次点击或切换模块会取消延迟校正；最多等待8秒，图片失败不阻断其他操作。不提交生成、复核或研究修改，不改变其他导航步骤。

验证使用当前真实A05及独立浏览器环境，拦截所有POST，检查首次载图、图片延迟、桌面/手机、重复点击和主动滚动取消。证据在仓库外`开发与验收档案/audit_20261019/kegg_map_navigation/`。
