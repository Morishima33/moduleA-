# 个性化参数界面：第一部分预览

## 入口与当前能力

打开研究工作台首页的“个性化参数预览”，或在旧“新建研究”窗口左下角点击“详细参数预览”。直接路由为`#/parameters-preview`。当前交付另启动独立本机预览服务，地址及截图记录在仓库外验收目录`audit_20261026/parameter_preview`，使用独立空数据根，不读取已有研究资料。

这是提前评阅界面的版本，不是已开放全自动研究。可以切换标准/个性化、编辑参数、调用真实后台校验，并下载当前已校验预览JSON。不会建档、保存研究草稿、启动计算或代签复核。旧创建窗口仍使用原固定流程；新参数不会被悄悄加入原创建请求。

## 页面内容

| 区域 | 当前显示及交互 |
|---|---|
| 分析方式 | 标准自动版使用只读默认值；个性化版允许编辑。切换标准模式不把自定义值当默认，切回个性化保留本页编辑 |
| 目标范围 | 从当前目录参数显示目标成分数×目标受体数；保留边界并列，不足按实际，不承诺每组都有有效评分 |
| A01成分与来源 | OB/DL、TCMSP/HERB/BATMAN采用规则。后台已接通，执行入口待开放 |
| A04网络与受体筛选 | 小数STRING置信度、Degree/BC＋CC/A/B三种互斥模式及A/B窗口。排序已适配，网络参数接续中 |
| A05富集 | GO/KEGG开关、BH阈值、图表前列数；更多参数解释条目背景基因数范围。执行适配待接通 |
| 对接与目标热图 | 目标成分/受体数、成分排序；更多参数包含Vina搜索、姿势数、能量差、种子、盒外扩和RMSD。执行适配待接通 |
| 固定规则 | 人类、固定Vina版本、BH、保留并列及按需出包，只读展示 |
| 校验与下载 | 使用原POST参数校验接口。修改任何参数立即清除旧校验；只允许下载仍与当前参数一致的已校验方案 |

所有默认值、范围与允许选项均读取同一后台科学参数目录。界面说明和接通标签为独立预览元数据，不改变科学参数定义，也不将“可编辑/可校验”等同于“已接通执行”。原始值、参数版本和后台计算的parameter_hash随预览JSON导出，文件明确标记`preview_only`及`unbound_to_study`。

用户认可其他部分后确认：目标成分数与目标受体数改为1—25的整数输入，可设2×2、7×16等目标范围，默认仍15×15。只改这两个目标数；A/B窗口及GO/KEGG展示数量仍沿用原选项。边界并列保留，实际数量按数据和既定规则解释。

## 用户如何验收

1. 打开预览，标准版应显示OB30、DL0.18，且不能直接编辑。
2. 切换个性化，修改OB或DL；打开各分组检查参数顺序、名称和解释是否清晰。
3. 在网络分组选择Degree、BC＋CC或A/B；A/B专用窗口只在A/B模式可编辑，数量选项沿用10/15/20/25，置信度显示0.90等小数。
4. 点击“校验当前方案”，应显示后台校验结果；通过后下载JSON，数值应与当前输入一致。编辑后下载按钮再次禁用。
5. 输入条目大小下限大于上限，或清空必需数值；应明确提示校验失败，不得默默用旧值通过。
6. 窄屏检查每项控件可读可操作；没有整页横向滚动。当前可评阅第一部分外观和交互，执行能力后续另验收。

技术检查由助手完成。浏览器实际操作、截图和下载JSON、接口回归结果与上传日志位于同一仓库外验收目录；截图及个人服务配置不上传GitHub。原固定科研内核、方案编译规则与历史静态资源保留。
