# Module A 衔接基础版使用说明

当前阶段：P1。已经有可运行的本机网页和统一数据交接内核；尚不能输出网络药理学、富集、分子对接或双报告结果。

## 打开工作台

在项目根目录双击 start.cmd。窗口会显示使用的 Python 和网页地址，然后打开浏览器。默认地址为 http://127.0.0.1:8765。

本机已验证的独立环境为用户 Scoop 安装的 Python 3.13.1；启动脚本会检查版本，不会误用系统默认的 Python 2.7。缺少合格环境时明确停止，不擅自安装。

## 现在可以操作什么

1. 创建研究：填写方剂、药味、已选疾病、疾病范围及登记人。
2. 在网页复核登记：查看中文摘要，必要时展开参数和原始字段，填写复核人、意见，选择暂存、通过或退回。
3. 查看各模块状态：登记通过后，成分与疾病模块会显示“条件已满足，科学模块尚未接入”，这是当前实际状态。
4. 修订登记：展开修订区并说明理由。程序另存新版本，不覆盖旧输入；新版本须重新复核。
5. 查阅历史：在网页查看全部复核记录与运行版本索引。高级字段用于追溯，不需要用户自己编辑。
6. 关闭与恢复：网页操作保存后可关闭。重新启动工作台，在“已有研究”中打开即可读取磁盘中的状态。

关闭启动窗口或按 Ctrl+C 会停止网页服务，已保存资料保留。当前没有长期科学计算任务在后台续跑。

## 文件在哪里

每项研究放在 studies/<研究编号>/ 中。中文方剂和疾病名称保存在登记信息里，网页直接展示；目录编号用于防止重名和串研究。

原始登记在 intake；各次输入和结果在 runs；人工决定在 reviews；manifest.json 是总索引。不要手工改写这些文件；发现内容需更正时使用网页修订入口。raw、normalized、reports 按大纲预留。

项目记忆见根目录 AGENTS.md。接口与字段说明见同目录《模块衔接与数据字典_v1.0.md》。源码在 src，逐行附简短中文用途说明；Python 和网页样式的专业细节不要求使用者掌握。

## 遇到问题

- 页面提示版本冲突：刷新，再对实际新版本确认，不重复提交旧页面。
- 提示文件缺失或校验失败：暂停该研究，保留资料让维护者核查，不补空文件或改成成功。
- 端口被占用：先检查是否已经打开同一工作台；不要重复开多个实例。
- 页面显示未接入：说明该科学模块仍待实现，不代表数据有问题。
- 待定科学问题：由助手先查大纲，不能确定时与你讨论，不自动更改规则。

## 维护入口

src/start.ps1 支持 Port、NoBrowser、PythonPath 和 CheckOnly 参数。CheckOnly 仅检查解释器和端口后退出。此维护入口不要求普通用户日常使用。

测试脚本放在 tests；虚构测试研究只在系统临时目录，web_home.png 和 web_review.png 是网页验收截图，不属于真实研究结果。

## 中文历史与可恢复回收站（P1.1）

“全部复核历史”现在默认显示中文表格：时间（UTC）、模块、对应运行、复核人、决定和意见。“全部运行版本索引”显示运行次序、创建时间、模块、原因、提交情况及当前/历史用途。原始字段在内层“技术追溯”区，不需要日常阅读。

移入回收站：打开某项研究，展开顶部“研究管理”，填写管理人和原因，勾选确认，点击“移入回收站”。该研究从正常列表隐藏，资料不删除、不移动。

恢复：在首页点击“回收站”，打开目标研究，展开“研究管理”，填写管理人和原因，勾选确认，再点击“恢复研究”。回收站期间仅能查看和下载，不能修改登记、审核或开始计算。尚未完整提交的运行须先处理，不能直接隐藏。

本版没有永久删除按钮，也没有独立管理员账号体系；这是当前本机工作台的管理入口。移入和恢复都有中文管理历史。模块复核记录与研究管理记录分开显示。

代码更新后，先保存当前表单，停止启动窗口中的服务，再重新双击 start.cmd。仅刷新浏览器不能替换已经运行的旧程序。旧研究自动兼容，不需要移动文件或重新录入。


## A01本地成分与方剂靶点整理（2026-09-10）

2. A00登记复核通过后，在A01卡片填写“运行或重跑原因”，点击“运行A01成分与靶点整理”。等待页面返回，不重复点击。
3. 查看中文摘要、各药味数量、成分、人类靶点关系及排除记录。全方去重成分数不等于各药味成分数之和；关系行数不等于不同靶点数。
4. 来源为本地TCMSP软件提取快照，数据库发布版本未知。OB≥30%、DL≥0.18只是预测筛选；人类基因映射来自原表，未自动在线更新。专业人员应结合来源和异常核验后，填写A01复核决定。
5. 展开“下载本次原始资料与结果文件”可获取筛选前相关记录、来源说明及所有结果表。下载文件只是副本；程序正式归档仍在研究包中。
6. 重跑保留旧版本；修改登记会使相关旧结果失效。关闭重开能读取已保存结果。此入口不会自动启动疾病、PPI、富集或对接。

本次固定快照的玉屏风三味药核查参考：原始关系3633行，OB/DL通过712行，其中人类702行、非人类10行；37个不同TCMSP成分编号，696条不同成分—蛋白—基因关系，211个不同基因符号。这些数值只描述该快照及筛选规则，不是其他资料必须达到的目标，也不是已经证明药效的结论。

当前尚无网页补充表上传、同义药名确认、在线基因校准或跨疾病自动复用按钮。缺药味时停止本次启动并提示核对；缺指标或映射异常单独留存，不会自动采用放宽条件。具体补充方案遇到实际资料后按大纲询问确认。


## A02候选资料整理：操作步骤（2026-09-10）
更新后先停止原工作台并重新双击start.cmd。当前A02允许收集和复核候选，尚不能批准给A03。

1. 在A00明确登记疾病并复核通过。若疾病填写COPD、慢阻肺或慢性阻塞性肺疾病，A02显示“导入COPD历史候选资料”；填写原因并勾选确认后导入。此入口只是旧资料候选，不是实时五库检索。
2. 查看“五库资料情况”。展开候选链接可按来源、名称或疾病关键词搜索，每页50条；翻页不会改变数据。原始名称数不是已核实基因数。
3. 打开“疾病条目范围复核”，先搜索相关表型关键词，例如chronic obstructive；选择当前页条目，填写直接条目/亚型/范围外/待核验、复核人和依据。保存会建立新A02版本。暂时不要求把旧OMIM所有条目都批准；无法确定就保留待核验。
4. 总体意见使用“暂存待定”保存。当前没有“通过，允许下游使用”，这是按已确认顺序保留的门控，不是故障。
5. 新资料通过“上传或替换一个数据库的资料”进入。选择来源、格式、编码并填写检索词、获取日期、版本和出处。UTF-8与GBK须明确选择，缺评分保持空白。每库当前一份来源，新上传明确替换该库，旧版本保留。
6. 通用TSV列为raw_symbol、raw_id、raw_score、score_name、disease_term、disease_id、relation_type；下载字段模板后按实际来源对应填入，禁止伪造缺失值。只有raw_symbol列为解析必需；来源信息在上传表单填写。原网站表格需先确认字段对应，不能仅改扩展名。
7. “在线获取OTP本病直接关联”要求输入已核对的疾病编号，例如COPD的MONDO_0005002。该入口关闭间接关联，保留原始分数；查询后再次核对返回的疾病名称和范围。不会自动导入全部亚型。
8. 展开下载区可以取得原始上传文件、来源清单、候选表及复核历史。来源文件与研究版本绑定，不需要回旧Kimi目录找输入。

OTP同分分页若未在有限补取中达到完整唯一ID数，会明确失败，不发布部分结果。此时可以重试或上传官方导出，不能把失败视作零靶点。
最终分数规则、基因标准化与正式疾病集合仍待讨论；当前结果用于查证资料和发现问题。与Kimi对比详见governance/P2_A02验收与Kimi对比.md。

## 通路推荐与人工审核（2026-10-08）

更新后关闭原工作台，再双击项目根目录start.cmd。进入研究页，在A05“通路推荐与审核（可选补充）”点击“查看通路图、解释与审核入口”；A07也提供同一入口。

没有候选时可登记准备请求，交由助手根据当前研究富集结果与疾病文献准备；这一步不会后台自动完成文献评审。候选准备完成后，直接看图、选择依据、解释边界及文献，填写复核人和意见，选择认可、暂存或退回。认可需明确勾选已核对；未认可不能加入报告。

认可后，如果尚未纳入，可点击“将已认可通路加入专业报告，生成新修订”。必需上游仍须通过；仅修订专业版，同源简略版保留，旧报告可追溯。已经纳入的版本不重复显示生成按钮；完整A07结论仍须单独复核。A05或相关科学输入改变后，旧推荐需重新准备和审核；通路选择或批准改变后，当前专业报告需修订。

新研究候选登记接口为src/pathway_review.py的register_candidate：需要当前A05编号与结果指纹、真实KEGG命中、相关靶点、图源与全部附件指纹、推荐理由、候选比较、原始文献和助手实际图件核验记录。仅登记为待用户审核，不自动批准，不默认沿用PI3K-Akt—AKT1。
