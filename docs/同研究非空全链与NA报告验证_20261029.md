# 同研究非空全链与NA报告验证

本阶段在一份通过公开新版建档的隔离研究中，接通实际三库/现代五库、交集、成分选择、PPI、固定R统计、结构不可用准备及生产双报告。全部外部输入明确合成，科学函数、发布入口和生产规范验证实际执行；没有用不同研究的局部结果拼成整链，也没有把测试复核写成用户或专家签字。

## 验证和修复

新增可重复集成夹具与三项集成检查，原上游两项继续验证；小矩阵、Word内容及其他图件的定向检查一并运行。核对实际JSON/CSV和文件指纹后，再从独立网页只读下载两份Word并渲染逐页看图，不以文档存在替代内容或版式核验。

本批5项非空/上游集成检查及11项图件/Word检查通过，共16项不同用例。当前非空研究386件登记文件SHA和490行CSV逐项比对，405个已有文件在只读核查前后保持；浏览器实际下载与归档字节一致，0写请求、0脚本错误。最终主报告9页、简略版8页，共17页均已逐页检查；科学原件与原复核保持，3个报告修订分别保留。

本阶段发现非空报告较长来源说明会单独占一页、小型NA图被放大为整页大字：新报告允许方法后自然接续网络章节，小型矩阵限制物理显示尺寸并居中，超长矩阵仍保持原20cm页高保护。科学原件、统计、方案和旧修订不改。

证据保存在重构根目录`开发与验收档案/audit_20261029/plan_reports/`：`nonempty_chain_v2/case.json`记录实际断点和运行编号；`nonempty_integration_tests.txt`、`nonempty_layout_tests_final.txt`、`nonempty_chain_validation.json`、`nonempty_browser_report.json`及最新Word渲染/目视记录分别对应测试、数据、网页和排版。初次合成完整性数量写错、受限R环境缺包及旧渲染均留存，不能混作最终成功证据。

## 仍未完成

这条链验证的是“非空网络/富集＋完整NA”，没有获得可用结构上的真实评分。还需在同研究可用结构批次核对评分、失败或部分成功的完整报告；随后完成一次明确确认的统一系统编排、科学原件中断续做和整体验收。当前阶段仍有明确合成测试复核，不能冒充最终全自动执行协议；正式研究也没有自动批准。
