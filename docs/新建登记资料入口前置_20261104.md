# 新建登记时补充方剂与疾病资料

新建研究页在方剂和疾病登记下方提供“补充方剂资料”“补充疾病资料”模块，提前展示资料要求，避免建档后再寻找上传入口。

## 操作

1. 在“新建研究 · 标准版／个性化版”填写登记和参数，点击所需资料按钮。
2. 点击“核对登记、方案与资料”，核对后主动勾选建档确认，再点击“确认建档并补充资料”。修改登记或参数后须重新预检。
3. 本浏览器页进入已绑定研究编号的资料工作区，可切换方剂、疾病两类资料。方剂复用三库原件获取与补取；疾病复用 GeneCards／OMIM 原件上传和其余公开来源获取。
4. 原件保存后查看实际状态；资料核对完成后可进入统一执行与续做。

选择按钮不创建研究、不上传文件、不启动任务。先明确建档，才能将原件绑定到本项研究。刷新已建档工作区可恢复研究与资料分类，不会重复建档或上传。未选择补充资料时继续原有普通建档路径。

## 实现与验证

新增前端路由 `#/creation-sources/{study_id}?section=formula|disease`，复用既有服务端接口、任务与来源归档；权限和科学规则仍由已有服务端契约控制。没有修改版本完整性、身份、结构、口袋或复核规则。

TypeScript 与生产构建通过。建档及疾病手动原件接口相关7项回归通过。隔离浏览器验证疾病、方剂、普通三种建档路径，验证改动登记使旧预检失效、确认不预选、刷新无写入，以及合成疾病原件实际上传与归档；1440／390像素页面无整页横向溢出，控制台与HTTP错误为0。隔离测试替代NLM身份响应，不代表新的真实研究或外部数据库获取通过。核查档案保存在仓库外 `audit_20261104/creation_sources`。
