# 新方案阶段接续与追溯

本阶段接通 A02 五库候选初始化、A03 原交集计算、A04 方案置信度网络的明确执行入口。每次只执行一个已就绪阶段，结果仍由实际核查人独立复核；全流程一次确认自动接续尚待实现。

## 网页操作

新版研究的 A00、A02、A03、A04 页面提供“本方案阶段接续”。先查看阶段条件与本方案 STRING 置信度，选择可执行阶段，填写执行人和依据，主动勾选确认后执行。默认不选择阶段、不勾确认；刷新和 GET 不发起执行。旧固定研究保留原界面。

| 阶段 | 已实现行为 | 继续保留的关口 |
|---|---|---|
| A02 | 有效 MeSH 新登记且无当前 A02 时，沿用原五库候选收集与解析 | 每库失败、未提供、疾病范围和身份问题保留；不能自动批准候选 |
| A03 | 从同一实际已批准 A01、A02 复算交集、两种完整排序及韦恩图 | 不修改父结果、不自动复核；新的方案成分选择接通前拒绝旧固定前五入口 |
| A04 | 将绑定方案置信度同时送入 STRING 请求、边过滤和复算 | 身份问题阻断；A03 批准或当前 A04 在联网期间改变则不能发布 |

运行中追加草稿不会更换本批已经明确确认的方案。已有同方案有效结果禁止重复生成；取消和中断不自动重试。请求过期必须刷新并重新确认，不能用旧请求换新参数执行。A04 与 A05 分别提供独立入口。

## 证据与导出

公开 Workflow 先在写锁内追加不可变执行确认及完整输入快照，成功发布后再追加完成回执。确认绑定研究、A00、方案、当前运行、最新复核及原件清单；回执绑定实际运行与结果文件。失败不写成功回执，不写人工 reviews。

追溯 JSON 增加 `stage_execution.requests/receipts`，导出前核验研究、阶段、运行、结果和全部所列文件 SHA-256。CSV 继续导出当前真实结果表；读取不改变 manifest。STRING 每次成功响应立即落盘，后续请求失败仍保留映射和错误诊断，未发布的原件可在本研究 `raw/A04_plan_acquisition` 查阅。

新协议分别为 `ModuleA.plan_stages.1`、`A03.plan_intersection.1`，A02 原科学版本与 `A04.plan_network.1` 保持。新增版本不回写原算法、历史结果或复核。网页置信度使用本批归档值；旧版本缺该字段时保留旧展示。

## 技术验证及边界

专项及相邻回归 28 项通过，包含实际 HTTP、真实后台子进程、参数过滤、读取无写、输入过期、复核撤回、联网中新草稿、失败保留映射、旧入口隔离、追溯篡改阻断及旧 A04 选择兼容。最终修订另有同组复验记录。

接口及资格读取还通过 `-I -S` 隔离启动核验：无第三方 site 环境，不加载 NetworkX、RDKit、python-docx、pandas 或 NumPy，四份研究 manifest 保持原字节。科学计算仍只在后台执行。

真实 Chrome 操作覆盖标准/个性化 A03、空网络 A04、只读 A02 资格；三次明确提交各对应一个任务，没有新增人工复核。1440/390px 页面无整页横向滚动，最终构建重新加载无自动 POST 或脚本错误。JSON/CSV 与归档逐行对照 111 条、逐件核验 131 个文件，四份 manifest 读取前后字节一致。截图已人工查看。
