# 新版A05分类、核译与展示决定

新版 `A05.plan_display.1` 在本批已完成的 `A05.plan_enrichment.1` 统计之外，追加分类、核译与展示资料。完整显著表、ORA／BH校正、原A05运行和人工复核记录保持；图表按该统计实际绑定方案读取独立的展示数量，不套用旧版GO前八或固定前十五。

## 网页入口与操作

打开新方案研究的 A05 页面，“本批A05分类、核译与展示决定”位于方案富集操作区之后。填写登记人和依据，主动勾选确认后点击“准备本批分类与核译资料”，后台生成同批分类、原英文对应核译和图件，不调用R。已开始但尚未完成的统计只显示原任务状态，不据此产生展示资料。

KEGG分类依据随本批归档的官方分类快照和实际登记中的已核验疾病身份。通用机制、其他疾病拟排除、分类待判断分别列出；拟排除不默认勾选。待判断条目可明确保留、排除或留因暂缓，每项必须填写依据；暂缓与排除分别留存，完整原显著条目不会删除。个性化方案未纳入KEGG时显示“不适用，不表示零显著”，不显示空分类表充当统计结果。

中文按稳定编号与本批原英文精确对应；词典中的核译和本研究明确核译分开保留，均不称为官方中文。英文改变或缺译时保留英文并标明待核译；填写本研究中文和核译依据后再明确保存。图／表所需条目缺译、分类尚未判断时资料仍待补，可保存未完成决定继续补充，不能把“已保存”当成科学批准。

保存决定后追加新展示版本。刷新恢复已保存的分类／核译内容，登记人、登记依据和整体确认仍须主动填写，不恢复确认或预选人工批准。展开“查看本批派生图表与完整导出范围”可查看和下载同批PNG及可编辑SVG。原模块人工复核仍在原栏独立进行，本入口不提交reviews、不改变A05/current、不调用旧continue或启动下游。

## 同批归档与追溯

请求绑定当前A05、其实际方案、上游及批准、最新同批展示和完整输入指纹。运行中另存草稿不会偷换本统计方案。准备／决定均保存不可变明确请求，来源原件、分类及完整显著范围译名快照、实现代码、决定、派生表和实际图件带相对路径、大小与SHA。后台锁外生成图件，发布前锁内重验，过期输入不能回写；来源损坏、回收站或未完成统计不能放行。

研究追溯JSON的 `plan_decisions.a05_display_requests/a05_display_records` 保留全部历史。CSV的原科学表名和数值保持，派生资料单独命名 `display.<display_id>.<table_name>`；展示暂缓、排除及核译不覆盖原始显著统计。图件下载仅接受已登记展示编号和图件序号，逐件核验，不接受客户端路径。

整批显著KEGG都被暂缓时，图件明确说明“原始显著…项，本图因展示决定暂不列项；完整统计保留”，不写“没有显著条目”。统计富集不证明通路激活、抑制或疗效。

## 实际验证与验收范围

模型与公开Workflow、生产HTTP／独立worker、图件下载、来源损坏、过期指纹、新草稿隔离、回收站、令牌／Origin、未完成统计页面及旧接口／追溯均有测试；最终不同用例数量见仓库外验证汇总，不累加重复执行。自检发现并修复未完成A05被展示资格及旧排名图上下文错误读取的问题，初次失败日志保留。

真实Chrome使用此前真实R产生的两份合成统计，明确准备与保存决定；展示worker固定不存在的Rscript，仍实际成功，证明展示不重算R。标准版两项未知KEGG留因暂缓，原始显著2项保持；个性化版GO各1项、KEGG未纳入保持不适用。首次浏览器测试因跨行下拉未实际选择第二项而留下一个未决，后端如实未放行；按各控件ARIA绑定确认生效后追加明确决定，原部分决定完整保留，没有重新计算科学结果。

两研究五版展示／请求与五项成功任务可查，独立实际R复验、224个文件SHA及505行原统计和展示JSON／CSV逐行一致；148件既有原文件字节保持，A05/current/reviews及读取前后manifest保持。最终服务重启和新构建后1440／390px只读回验零POST、零脚本错误、无默认确认或批准，未纳入KEGG文字明确；网页、真实PNG和SVG说明已检查。关闭第三方site后两研究完整追溯可读，未加载科学库或PIL。
