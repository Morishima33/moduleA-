# 新版同批双报告与真实追溯

本阶段将新版报告从模板层接入真实生产任务、网页下载和研究追溯，协议为`A07.plan_report.1`。旧报告、旧人工关口和冻结第24版模板保持原版本行为。当前验证使用明确标记的隔离流程测试研究，不是用户正式研究复核。

## 网页入口和预期行为

进入新版研究的A07，在“本批报告”区域查看实际条件。报告登记人、依据初始为空，确认框默认不勾选；条件齐备并明确确认后才提交后台任务。生成后下载“主报告.docx”和“简略版.docx”，历史版本分别保留；页面读取不会开始任务或代签批准。

实际交集为零时，报告列出真实方剂/疾病来源、参数、集合数量和不适用分支，不运行PPI、R或Vina。交集非空而适用分支未完成时，页面说明等待原因，不能生成虚假完整报告。已出现人工暂存、退回或撤回决定的来源不能被另一次系统一致性校验放行。

## 同批事实、图件和依赖

- 方案取自实际A03运行登记的方案文件，不读取后来追加的未采用草稿。新增草稿不改变正在生成的旧批报告；实际来源、选择或复核改变仍会阻断。
- 方剂、疾病、交集、PPI、富集、结构准备与评分必须属于同研究和当前有效依赖。A05读取本批原统计与来源快照，不重新运行R；对接不填零、不用其他低排名对象替代NA。
- 报告依赖保存真实`parent_validation_records`及`execution_authority=system_validation`，人工`parent_review_ids`为空；不改`approved`、`latest_review`或人工审核文件。
- 双报告同时归档。集合图无交集时分离两圆；网络保留实际孤立节点；完整评分矩阵保留全部行列与NA，按实际范围分页，图内阈值标记使用原始分数。中英文缺译保持原名与待核说明。
- 同批PNG/SVG、实际参数、生成实现代码、字体名称及指纹和完整原件SHA一并追溯；不将通路统计解读为实验或因果证明。报告中的数量旁说明对象、来源与范围。
- 失败请求、诊断和不完整文件保留；新明确请求另建运行，成功历史不覆盖。追溯JSON及CSV在导出前逐件核验文件。
