# 新版结构准备入口与同批导航

新版 A06_PREP 页面现在能从已保存的固定输入明确启动实际第二版结构／配体准备，并定位同批口袋、共晶、整体复核和评分入口。复用原科学内核和隔离工具，不修改旧准备接口、算法、阈值或已保存结果。

## 操作与预期

先完成本研究成分与受体的独立选择、复核和固定输入，再打开“A06 对接对象与配置复核”。页首“本批结构与配体准备”显示实际成分数、受体数、完整组合范围以及绑定方案的搜索投入、姿势数、能量范围、种子、搜索盒外扩和RMSD上限。

填写执行人和依据，主动勾选确认后启动。后台重新核对固定输入、当前准备、方案及上游复核快照，归档明确请求，再运行原 `plan_preparation_v2` 隔离科学过程。网页不传入路径、参数、名单、质控状态或评分。

准备完成后展示实际可用／NA／已评分数，成功归档同批结果后不重复连接。来源或身份失败保留对象、全部组合和原因，不以其他成分／受体补位，不填零。准备完成不代表可以批准或评分，口袋采用、共晶参考、整体复核和评分各自保留明确关口。

| 情况 | 实际行为 |
|---|---|
| 输入、准备或复核已变化 | 旧请求拒绝，刷新后重新确认 |
| 没有工具、任务正运行或回收站 | 显示具体阻塞，不启动科学过程 |
| 已有同批有效准备 | 回读结果和后续证据，不默认重算 |
| 科学进程失败或中断 | 原请求和已产生原件保留，无成功回执；当前指针变化后须刷新并以新请求明确重试 |
| 同批准备尚未完整归档 | 页面可读；任务仍运行时不能重复执行，不提前加载共晶操作 |
| 只有NA、没有可用组合 | 保持空评分和质控阻断，不能自动进入整体复核或评分 |

导航只定位真实现有环节，不启动任务。后存方案草稿不改变已绑定输入参数；“前往评分”只进入评分区，是否可执行仍由实际资料和人工批准决定。所有确认框和新的复核决定初始均不预选。

## 归档与追溯

新入口协议 `ModuleA.plan_preparation_ui.1`。请求固定完整输入／复核指纹、实际登记人与依据；成功回执核对真实第二版事实包、当前运行和精确固定输入文件。科学失败只有请求与原件，不写成功回执或人工 reviews。

研究追溯 JSON 的 `plan_decisions.preparation_requests/preparation_receipts` 逐项保留记录、关联运行、结果和文件指纹。导出验证请求内容及输入快照指纹、回执研究／运行关系和递归来源SHA。CSV继续输出同批实际结果表，准备NA与评分缺失不转为0。
