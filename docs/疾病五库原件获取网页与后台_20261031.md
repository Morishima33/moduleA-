# 疾病五库原件获取：网页与后台接续

2026-10-31。统一执行页已接通明确获取、原请求补取、逐库原始记录数与失败原因，以及独立科学后台任务。科学来源与恢复规则沿用 A02.system_acquisition.1，未改原采集器、范围规则或旧科研批准。

## 入口与操作

进入新版研究的“统一执行”页，在“补齐疾病五库原件”中核对已登记疾病、填写登记人和说明，主动勾选确认后获取。GET、打开页面和打开补取确认框均不执行；任务完成后页面显示实际记录。旧服务没有本项能力时隐藏该区域。

“按原确认核验或补取疾病原件”保持原方案、登记人和说明，仅补可获取的缺失来源；成功原件核验后复用。补上传使输入变化时须按当前状态重新确认，旧请求不会套用新资料。GeneCards、OMIM仍需本研究原件；缺失、查询失败、有效零条分别显示，不把缺失写成零。

本区只保存原件。**疾病候选发布和由新原件进入科学批次仍待接续**；完整归档不代表 A02 已发布或研究结果已批准。
