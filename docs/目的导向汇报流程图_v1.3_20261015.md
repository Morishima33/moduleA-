# 目的导向汇报流程图

依用户要求，参考旧汇报版的蓝紫绿分区、圆角节点及左侧溯源旁轴，按最终操作流程重新绘制。阶段标题改为简短目的，具体工具和操作写在标题下。

| 阶段 | 简短目的 | 主要操作与输出 |
| --- | --- | --- |
| 对象 | 明确研究对象 | 方剂与药味、疾病MeSH官方核对、仅本病范围、人工确认后独立建档 |
| 资料 | 汇集可靠靶点 | TCMSP/HERB/BATMAN-TCM及现行疾病五库，分库留存与身份核对 |
| 候选 | 筛选候选对象 | 共同靶点、交集靶点数主排序、混合Degree参考、人工确认对接成分 |
| 分析 | 识别网络与功能 | 完整交集进入独立PPI和GO/KEGG分支，双分支两轮筛选、A/B及富集图表分别复核 |
| 结构 | 评估结合潜力 | 核准成分与受体、单独确认结构与预算、质控、固定参数计算并独立复核 |
| 交付 | 形成研究报告 | 原始评分及姿势、可选按需出图、同源双报告与统一附录、人工复核后发布 |

本版明确：成分确认只控制对接，不截断PPI与富集输入；富集直接汇入报告，不是结构计算前置步骤；按需出图是可选支线，不要求预生成所有组合。严格结果与单项获准试算分开，不能通过模板改变科学含义。
