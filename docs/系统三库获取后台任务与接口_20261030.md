# 系统三库获取后台任务与接口

本阶段把已实现的 `A01.system_acquisition.1` 接入真实HTTP和独立后台任务，尚未新增网页按钮或接入后续科学批次。代码上传不等于当前正式服务已经重启；用户无需运行脚本验收后台，后续页面整合后统一验收。

GET `/api/v1/studies/{sid}/analysis-plan/system-acquisition`显示获取条件、已明确请求、逐库恢复记录、实际整批结果、失败和明确重试资格。POST同路径`/execute`只接受原七项确认字段；新请求绑定当前方案，原请求按原内容重试，后存草稿不替换其门槛。严格字段、令牌、Origin、过期、忙碌及回收站保护保持。HTTP只预检和排队，科学验证与获取在 `plan_system_acquisition` 独立 `-I -S -B` 子进程中完成。

任务沿用现有资源位、进程树取消和日志。排队后再次核对登记、来源及原人工意见，已被明确暂停的研究不会获取。部分获取失败必须任务failed，已取得的合格库仍保留，并可明确重试原请求；完整原件重复请求只复验。GET和服务重启不自动提交。原科学A01、当前运行、人工复核和旧上传指针保持。
