# 系统三库获取网页与补取

本阶段在统一执行页加入“补齐三库原件”，使用已验证的获取协议与真实隔离任务。入口为研究A00的“打开统一执行与续做”，页面 `#/system-pipeline/{sid}`。新服务必须明确提供system_acquisition能力，旧后端不显示或请求新获取接口。仅在19880合成预览加载新代码，正式服务未重启。

用户可核对当前方案的TCMSP OB/DL，填写登记人和说明，主动勾选确认后点击“确认获取三库原件”。任务结束显示三库实际状态和原因。首次未勾选；输入或方案变化清除确认；网页读取、刷新、任务完成和重启均不自动提交。网络失败保留请求编号，409只刷新，不自动重交。

已有请求提供“按原确认核验或补取”，窗口展示原方案门槛，明确继续后复用原确认。后来另存草稿不替换原请求。逐库成功检查点与整批结果分别显示；整批尚未写成不会显示complete。获取成功仅归档原件，尚未自动衔接科学标准化或科学批次；原件齐全后仍须满足实际HGNC、五库和关键身份检查，不能据此当作科学A01发布或人工批准。
