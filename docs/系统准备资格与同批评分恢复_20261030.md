# 系统准备资格与同批真实评分恢复

新增 A06.system_quality.1 与 A06.system_qualification.1，在本批已归档系统准备上派生新的真实资格运行，不重取结构、不重做Meeko、不改选对象。严格参考仍委托原参考质控及2Å/更严方案上限；预测路线核验同一蛋白身份、结构和必要环境、两次首位P2Rank原文件及原盒，AlphaFold继续使用局部80/70/10和实际序列范围。明确系统探索资格有独立system_decision，不填旧pocket.confirmation，不冒充人工reviewer/confirmed或reviews。未知身份、环境、不同预测和不合格置信度保持NA。详细尝试存事实附件，标准结果表只含简单单元格。

新增 A06.system_scoring.1 与 Workflow 专用资格/评分入口，绑定当前实际准备及同批一次授权、原固定参数和生产科学回执，不接受客户端路径/名单/科学参数覆盖，不造parent_review_ids或preparation_review。实际Vina1.2.7逐组合、单CPU执行；命令、工具SHA、PDBQT、盒、实际Top-1、日志、返回码、完整矩阵和生成源码留存，严格/探索分列，NA保留原原因和空评分。独立生产注册表复算，即使调用方设lambda假校验也不能伪造严格计数或评分。

本批评分中断后，显式相同请求恢复同一run；逐件核验已存在完整execution.json及其命令、输入、返回码、Top-1和构型，完成组合只读复用，只执行无完整执行证据的组合。成功或已明确失败执行均不自动重算；损坏原件、多完整结果、工具/实现改变、上游或人工决定改变继续阻断。未完整尝试目录及失败诊断保留，不覆盖。不声称已实现结构下载/不完整准备中全部逐位点恢复。

整链自检复现同一准备再次通过校验导致既有评分误失效。仅本新评分协议允许保留实际已采用且对应同一run/input_hash的真实通过回执；最新校验仍须通过且可交接。新通过回执不改变既有评分，最新失败、原件或人工变更仍阻断。其他既有系统/人工协议语义保持；科学发布前新的依赖快照仍锁内核对。资格失败诊断纳入已生成但未发布的run文件。

A07显式适配系统评分协议，仍从同研究实际固定范围与完整结果重建，不能把新记录伪装成旧人工评分输入。两份Word共用真实分数与NA，9模块真实生产规范证据保留；原R和历史报告不重算、不覆盖，正式A07仍待人工结论复核。
