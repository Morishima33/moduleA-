# 系统受体选择与固定准备范围

新增 ModuleA.system_decision.1，在已明确的同一系统批次内形成 A04_SELECTION 与 A06_INPUT 两份独立记录。实际父运行必须来自该批系统执行结果，并逐件具备真实生产规范回执；不调用旧 approved 门控，不构造 selection_review_id、人工父签名或人工选择复核。

受体使用原 select_from_network 及三种原筛选算法，读取本批真实完整指标与方案。默认目标15、A/B先后、两轮规则、边界并列及实际不足均保持。固定准备输入为新 A06.system_preparation_input.1，绑定实际 A00/A03/A03_SELECT/A04、原方案、系统受体选择、真实父校验、原结果和完整成分/受体；human_reviews为空且不代表人工批准。准备失败不得替换名单，完整笛卡尔组合保留NA与实际原因。

运行中新草稿不替换原批次；发布前核对上游、人工决定及实际实现源码。幂等提交不重算，人工暂存或退回使关联失效；失败独立保存，不产生伪成功名单。归档包含实际算法源码，读取与追溯不执行筛选或加载科学环境。完整JSON及CSV均含新名单和固定范围；CSV的派生选择运行号为空，独立表名和元数据明确decision_id与绑定运行，避免冒充科学运行。

验证：8项不同新系统选择用例（原7项＋2项补查中1项重测）及14项旧参数API、三种筛选和追溯兼容，共22项不同测试通过。独立六阶段原件副本接续，目标15受体按原五星网络规则实际仅1个；2成分×1受体固定2组，NA状态传播保留全部组合、原因及空评分。198件SHA、518行CSV、223件已有文件核对通过；零新增人工复核，不改变六阶段科学当前运行。-I-S禁用第三方环境只读通过且未导入system_input科学适配。

证据在仓库外开发与验收档案/audit_20261029/plan_reports，前缀system_decisions：tests、additional_tests、compatibility_v2、validation、stdlib、case和trace。首次本机HTTP测试连接被系统拒绝，改用正常本机权限后14项全部通过；初始诊断保留。测试网络与疾病背景明确合成，不是实际科研验证。

此阶段仅内部系统记录与固定输入，无新网页入口。新固定输入尚未接入真实结构来源、Meeko/P2Rank/参考配体质控或Vina；NA状态传播核查不代表已经执行准备。旧人工选择及准备输入协议保持，整套automatic_execution_available仍false。下一步接真实准备、严格/探索/NA及评分的系统依赖，随后统一后台编排和科学原件续做、统一验收。
