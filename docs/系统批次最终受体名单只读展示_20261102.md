# 系统批次最终受体名单只读展示

系统批次A04页面此前隐藏了旧人工选择表单，却没有直接展示已经归档的系统最终名单。现在新增只读名单区，从本研究、当前网络、同一次明确批次的A04_SELECTION原件读取原顺序、HGNC编号、A/B组别及原始中心性指标，和下方全网两轮候选统计分别展示。

目标数与实际数均来自原归档，保留边界并列，不在界面重新排序、截断或选择。缺少决定时显示待归档，数量为空；实际已归档空结果才显示0项。存在同源A06_INPUT时显示已固定的成分数及完整组合数，尚未归档时不推算范围。

新增模块GET可选字段system_receptor_selection，旧服务缺字段时隐藏。展示桥接核验归档文件SHA、请求/输入/内容指纹及研究、批次、网络绑定；只读取已登记档案及本次模块已核验来源，不重复展开所有科学来源，也不提供执行或复核资格。执行器的完整规范校验继续保持。

该区仅有统一执行进度链接。没有新增POST、保存、采用、复核或默认勾选；旧人工流程、历史页、当前模块状态与独立复核门控保持。其他批次或其他网络的名单不作为当前最终名单，原件改变会被拒绝。名单固定后，结构或质控失败保留原位置与NA原因。

本轮验证：来源隔离、并列/原序、空与缺失、固定输入绑定、篡改拒绝及相邻展示20项检查通过；当前系统/历史/未获准阻断另2项实际整页回归通过。TypeScript与构建通过，旧静态资源保持。独立本机服务的真实HTTP名单逐项与原归档一致，1440/390页面读取零写请求、零脚本及HTTP错误；旧API隔离合成研究实际核对无新字段时隐藏。桌面整表、手机顶部/底部及真实身份详情宽窄屏原尺寸图像均已查看。最初裁图遮挡标题、旧版真实页面读取未完成的中间记录保留，不将其冒充最终通过；兼容验证明确使用旧服务的隔离合成研究。研究结果、上传及用户最终验收状态仍以独立交接记录为准。

另修正当前系统A04先构建旧候选、身份补查和人工名单表单、随后再隐藏的重复读取。现在只跳过这些最终不展示的内容，原结果、状态、来源指纹和复核门控仍逐次核验；历史与普通人工版本不变。回归同时核对已获准清单限制显示、未获准未决仍阻断，以及历史页不提供当前名单。
