# 结构准备逐对象断点恢复及系统结果页

本阶段完成新批次结构准备的逐对象保存和明确恢复，并接通系统资格、实际评分、报告和网页只读展示。它解决准备进程中途结束后，整包尚未生成而重取、重做已完成对象的问题。正式研究及统一验收尚未完成。

## 已实施的范围

- 新网页确认继续使用原七字段，请求不能覆盖工具、阈值、对象或版本。公开 `start_analysis_plan_recoverable_system_batch` 固定 `A06.system_preparation.2`；同请求重试返回原批。旧开始方法、旧批次、准备/资格/评分1保留。
- 新会话 `A06.system_preparation_checkpoints.1` 绑定原批次、系统固定名单、完整配置、真实Vina字节和18件科学实现快照。每个成分来源、成分准备、受体来源、原顺序受体候选尝试和受体准备完成即不可变追加，不等整个准备包。
- 明确续做先核验对象及全部依赖文件。成功来源不重取，同来源已准备对象不重做，已完成受体候选尝试复用原证据和原规则复算。来源NA在整包尚未完成的明确续做中可以补取；已完成整包只复验，不因NA自动重启。未完成目录保留，新尝试另名保存。
- 原件损坏、原范围或人工决定变化、工具或科学实现字节变化均拒绝续做。不会另建会话掩盖不兼容，不从多个竞争会话择优，不替换失败对象，不降低科学阈值。
- 显式新 `A06.system_qualification.2` 和 `A06.system_scoring.2` 只消费对应新来源，原Meeko、结构顺序、P2Rank、几何核查、RMSD、Top-1和逐组合评分恢复规则保持。完成事实进入生产规范复算，调用方假校验器不能放行伪摘要。
- 接口进程只依赖标准库；网络和外部工具在原独立科学worker执行。每个对象开始和发布前重新核对原批、父回执与人工意见，短写锁不包围网络或工具执行。沿用同研究单写任务、全局资源预算、取消进程树保护。
- 系统准备/资格/评分1及2的结果页读取本运行固定名单和原归档，不再落入旧“尚未启动”提示。显示实际数量、原始评分、严格/探索及完整NA，名称不借用最新草稿或其他研究；无有效评分不画空热图。旧执行区隐藏，人工复核仍独立保存。恢复仍使用已有“按当前状态续做本批”，没有新增逐对象操作卡。

## 网页入口和检查方式

新代码目前仅加载在独立合成预览服务 `http://127.0.0.1:19885`，未重载正式服务或已有19880/19883/19884服务。静态前端不变，复用原请求和热图组件。

1. 打开独立预览研究的“研究登记”，进入“统一执行与续做”；完成批次仍显示“报告待结论复核”。
2. 点击“按当前状态续做本批”，后台任务应成功，已有运行、报告和对象检查点保持。打开页面、刷新或重启本身不提交恢复。
3. 打开A06：本合成例固定2成分×1受体，实际评分1组、准备NA1组、评分失败0组，严格0、探索1；完整矩阵同时显示评分和NA，原因表保留明确缺失成分说明。
4. 打开A06_PREP：显示准备可用1、准备NA1、严格受体0、探索受体1，以及同批实际质控依据，不提供旧自动连接操作。
5. 打开A07：两份Word可下载，未产生人工批准，报告用途和范围保持流程测试。

此预览使用虚构疾病、身份、来源响应和合成结构几何，不能用于研究结论。正式研究不需要用户运行技术检查脚本；上述技术自检已由助手执行。
