# 统一执行与续做网页入口

新建方案研究的当前A00页面提供“打开统一执行与续做”，独立地址为#/system-pipeline/研究编号。服务器session能力system_pipeline为true时才显示入口；仍运行旧后端的服务读取新静态文件也不显示不可用按钮。统一后台算法和原参数不在本轮改写。

页面显示本研究用途、服务端资料预检、已保存方案参数和可执行条件。首次执行须填写本次执行人、执行说明并主动勾选“我已核对本研究资料和本批方案”；默认不勾选，不把姓名或说明视为科研复核签名。参数只读，不在浏览器重编译、推算结果或静默改草稿。过期输入先刷新，网络失败不自动重复提交；同内容保留请求号。

已有批次显示原绑定模式和参数、真实流水、中文阶段/状态、不适用与失败原因，允许按当前指纹明确续做。后加草稿与原批分开展示，独立测试新草稿seed7、原批seed1保持。续做使用原已明确授权，不再逐阶段让用户确认；保存的有效科学运行和同源报告不会重复生成。既有后台面板跟踪真实长任务，终态再刷新；报告链接返回A07下载/独立复核区，不预选通过。

资料预检仍要求本研究已提供三库、现代五库原始候选和HGNC。原来源获取自动补齐及标准化后新方案对原五库的显式复用还需继续接入，不能将当前尚需绑定原候选误说成原件不存在。缺失/版本/身份或环境问题仍保留原因，不填零、不换排名、不调整参数。整体科研流程与真实病例全链尚待验收。

本轮14项不同真实HTTP/worker、原方案/新草稿、session能力及旧API兼容检查通过，类型检查与最终生产构建通过。Chrome实际首次未勾选禁用、填写内容不代替确认；主动确认只出现1次start POST，独立科学后台任务成功，空交集8项不适用与双报告回读。再主动点击续做只出现1次continue POST，第二个真实worker成功且current/runs/reviews和原报告不变。合成研究只有1批次、28条流水、0新增人工复核；脚本/控制台/HTTP错误为0。

独立标准库-I-S核对174件追溯SHA、78行CSV以及完整流水；未导入numpy/pandas/rdkit/networkx/docx/PIL。共5张桌面和390px截图实际打开，未见裁切重叠或整页横向滚动。参数两列表格随窄屏自动换行、同时可读，不再要求将长表滚到底部横移查看保存值；多列流水只在表格自身横向滚动。
