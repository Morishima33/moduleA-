# 网页新建研究与文件隔离（2026-10-16）

用户授权补齐新建入口，并要求做好对应文件管理。首页及研究页顶栏均提供“新建研究”，由用户明确填写方剂、药味、疾病、MeSH首选词与编号、用途和登记人；服务端复用原NLM核对及Workflow.create。身份不匹配或网络失败时不建档。成功只生成A00及原始登记，不自动批准、不创建计算任务。

## 文件管理

每次新操作使用独立study_<唯一编号>，不使用病名拼路径。同病重复建档仍分开，旧项目索引和文件保持原字节。项目内intake/、raw/、normalized/、runs/、reviews/、reports/分别保存登记、原始资料、标准化资料、运行版本、复核与报告；后续专门确认可由原流程生成decisions/等目录。所有历史版本按原规则留存。

沿用当前服务配置的数据根。其目录名虽然含旧快照日期，各新项目仍在studies/下按唯一编号隔离，不表示创建日期相同或共享结果。首页显示编号，研究页“项目文件夹”显示实际保存位置及目录说明，并支持复制路径。运行去重账本放在私有runtime/study-creation，核查过程文件集中到开发与验收档案/audit_20261016/create_study，不在重构根目录堆积。

POST /studies采用明确提交编号：首次201，成功后的同一登记重试200并返回原项目，字段变更冲突409。新建操作每次使用新编号；服务重启或运行记录丢失后，沿经内核核验的A00恢复，避免重复目录。服务器不接受客户端指定证据、物种、路径、批准或自动计算选项。Host、Origin及令牌校验沿用原接口。
