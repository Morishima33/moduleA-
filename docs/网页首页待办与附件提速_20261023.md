# 首页、待办与附件读取提速

本轮只优化网页性能，基于8321a23继续；科学内核、阈值、评分、研究输入、复核及冻结报告保持。没有启动新计算或改变研究状态。

## 修改

- 同时发生的同URL GET只发一次，各组件取得独立JSON对象；完成和失败立即清除。POST开始/结束均清空进行中的读取登记，写后刷新重新获取，不合并POST。
- 首页卡片与全局待办按研究索引及活动任务版本合并进行中的组装；独立研究最多三项并行，保留原序。研究列表仍按更新时间排序，待办顺序保持。
- 同一研究/运行/索引版本的表格与图像并发读取共享进行中的完整核验；后续独立请求重新核验，所选附件仍逐件核对指纹。
- 附件与静态资源用256 KiB分块发送，避免发送前再分配完整文件内存。原下载字节、长度、文件名和安全响应头保持。
- 首页、回收站及顶栏待办忽略已过期异步响应，避免刷新后旧请求覆盖新状态。保留上一版前端资源，兼容已打开页面。

## 验证与边界

隔离测试使用虚构研究，检查并发合并、容器隔离、版本/任务变化、失败后重读、写前写后失效、令牌重试、下载字节与篡改阻断。真实研究只读核对首页、待办、A01/A02/A05/A06、历史及GO/KEGG图片；真实浏览器检查首页和图表页，阻断所有写请求。

首次实测（同机、Edge无头1440×1000、相同三项研究）：首页卡片10.514→7.016秒，同一份待办请求2→1。耗时随磁盘缓存、归档大小和同时打开的页面变化，不作为固定承诺；保留完整核验，因此页面仍可能有数秒等待。本轮不代表科研计算速度变化。

上线复测：首页7.024秒，A05全页请求11.473→9.584秒，A05首屏7.170→7.680秒，首屏尚未改善。宽屏和390px窄屏无整页横向溢出，实际图片加载成功，无页面错误及科研写请求。修改前后8项JSON响应逐项相同，GO/KEGG图片字节及安全响应头相同。
