用户在A03看到方剂210、疾病0、交集0，要求核对上下游对应关系及方剂成分数量。已逐项核查当前研究的A01原始来源、筛选排除、标准化、A02候选与已保存范围、A03实际父运行；本次技术修复不改变科学参数、来源选择或人工批准。

## 本次诊断

| 对象 | 归档事实与解释 |
|---|---|
| 当前方剂输入 | 实际采用TCMSP单库；37个筛选后不同成分，38条药味归属，共享成分不重复计为独立成分。210是不同标准化靶点基因数。 |
| 方剂筛选链 | 3633条原始关系，712条通过既定OB/DL，702条人类关系，去重为696条；明确身份例外处理后684条标准化关系，对应210个基因。所有原始证据和排除原因仍留存。 |

| 当前疾病输入 | 五库12084条候选资料已读取，但384组疾病范围全部为outside，因此标准化基因及交集均为0，计算与其实际输入一致。 |

| A03版本对应 | 210及0均来自本交集实际绑定的A01/A02标准化版本，没有把当前另一项目结果拼接进来。 |

新研究的既有自动A01入口沿用TCMSP基础资料路径，HERB/BATMAN并不会由该入口自动采集；目前有三库独立上传及整理入口。增加界面提示不能补造缺少的来源，也不能把旧研究现成结果当作本研究三库已经处理。补齐或明确重用本研究可用的原始三库资料后，才能独立整理新版并复核。

## 修改内容

1. A01/A02/A03标题与导航后增加“输入来源与数量核对”。明确区分成分、关系记录和标准化基因；实际库名与三库缺口可直接查看。
2. A03仅解释父运行所绑定的A01/A02，提供输入版本查看入口；比较父子归档数量以发现不一致，绝不重算或补造交集。
3. 疾病为空时展示候选记录和各范围组/记录计数，明确区分范围排除、待核验和标准化后的真实空集合；提供返回当前A02范围表入口。
4. 空集图用虚线框，没有交集的两个非空集合画成分离圆；正常非空交集继续用原两圆展示。
5. 范围表增加“仅排除待核验条目”。只把本地表单当前pending改为outside，保留direct、subtype、outside等已决定行；不自动保存、签署或触发标准化。
6. 隔离回归覆盖“已经生成空标准化集合→重新保存范围→重新身份预览”的原有修订路径，旧版本保留，新范围不自动批准。
