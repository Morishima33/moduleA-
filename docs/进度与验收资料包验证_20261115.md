# 进度与验收资料包验证

本批在既有任务、检查点、研究索引和结果读取层上追加展示，不新增队列或科学恢复框架。准备、组合、区域分别计数；完整区域组终态后才计完成组合，局部区域失败可保留成功组合。无区域登记的旧评分不造区域，未固定区域总数显示未知，不凭空估计剩余时间。当前对象来自原任务日志进度，最新时间来自已登记记录。已完成评分与 NA 分列。

`GET /api/v1/tasks/{task_id}/scientific-progress` 仅适用第一/二版受体补救，绑定原任务完整请求和科学运行；其他任务保持原阶段及日志展示。首次和退出核验复用同请求只读证据范围。进度纯计数测试通过，但完整真实 COPD 检查点的端到端进度展示仍待原环境验证。

验收资料入口只读取指定运行已登记的结果、构象、参数、来源、失败原因和图件。完整与焦点矩阵、CSV、SVG、保存的视图 JSON 按同批重建核对；PNG核对登记字节、CRC和尺寸，没有在 HTTP 中重新绘图。缺译或当前图件缺失会阻断最终 ZIP，不静默补算。不生成 Word、不写人工复核。ZIP 目录与指纹列明实际成员长度和 SHA；下载头提供实际 ZIP SHA。

验收 ZIP 仅覆盖补救结果版本，不是通用任意模块导出器；已有项目原导出入口保留。512MiB 以上资料包拒绝内存打包，应逐附件下载。旧历史附件和 Word 不覆盖；资料包不产生新 Word。
