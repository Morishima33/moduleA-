# 验收资料包重复登记原件的只读合并

## 已定位的生产结构

当前科学二版compute把rescue目录全部原件以rescue_evidence收集，又将实际图件和CSV等附件以语义角色登记。
Workflow._finish按sources、figures、attachments保留完整关系，不保证文件路径唯一。这是合法登记形状，不能改冻结科学代码或历史结果去消除重复。
原验收ZIP逐记录以registered/原路径加入成员，遇同路径会报“验收资料包成员重复”。相同图件若重复以同一语义角色登记，资格检查也会先误报角色重复。

## 修复范围与选择

只修改API打包与相关测试、契约。不改科学producer、Workflow、运行结果或既有历史包。
按原登记路径逐项归组，只允许路径、长度与完整SHA一致的记录共用一份不可变下载字节。
同路径不同长度或SHA必须阻断，不能按文件名、成分名或先到记录择优；不同路径即使同字节也分别保留。
ZIP每个原路径只保存一个成员，清单同时保留每条原登记索引及完整原记录，来源/语义角色不丢失。
同一图表角色重复指向同一原件可接受，指向不同原件仍保持原冲突门槛。
512MiB原限制保持，按实际唯一登记成员计算，不让重复引用重复占用内存预算。
逐成员完整SHA、同批输入、Top-1原字节、缺译/缺图门控和导出末尾manifest检查保持。

## 执行与验证

1. 用现有合成真实文件/执行fixture按生产双重角色登记形状复现ZIP拒绝，先红后修。
2. 新增小型归组辅助函数，资格检查保留所有角色，ZIP仅合并同路径同身份的字节。
3. 验证清单保留全部原登记，重复角色可下载，同路径冲突/不同对象/损坏仍拒绝；不同路径同字节不合并。
4. 验证完整矩阵/CSV/图件和MODEL1一致、GET不新增研究文件、末尾版本变化拒绝。
5. 自审、必要定向回归与正常HTTP实下载后，按精确清单上传已授权development；生产部署单列。

真实A06尚在计算，测试通过不代表最终真实资料包已经可下载或完成科研验收。未经要求不生成真实Word。

## 当前技术验证

原ZIP路径重复与同角色重复两个用例已先复现失败；修复后验收包及实际构象HTTP相关21项通过。
覆盖同一路径同字节的多角色/重复角色、全登记关系与原索引保留、两种顺序的冲突长度/SHA拒绝、
不同路径相同字节不合并、同图表角色不同路径仍拒绝，以及合成HTTP实际ZIP的SHA响应头和MODEL1。
只用小型合成数据替换预算阈值验证唯一字节边界，无大文件或实际预算变更；原阈值仍512MiB。
导出末尾登记变化明确拒绝返回，逐个成员指纹与原研究文件不变均已核对。
原包/图/CSV损坏、缺译与缺图门控保持。静态独立复审未发现Important，建议的预算及末尾守卫已补测。
