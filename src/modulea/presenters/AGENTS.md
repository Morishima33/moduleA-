# presenters/ — 模块展示适配

每个模块一个展示函数 `present(result, ctx) -> Parts`，在 `__init__.py` 的 `PRESENTERS` 登记。

| 文件 | 模块 |
|---|---|
| `registration.py` | A00 |
| `sources.py` | A01、A02 |
| `intersection.py` | A03、A03_SELECT |
| `network.py` | A04、A05 |
| `docking.py` | A06_PREP、A06 |
| `report.py` | A07 |

## 规则

1. **只读已归档结果**：输入是内核已核验指纹的 `result.json`；不联网、不读其他目录、不写文件、不做科学计算（排序、取前 N、求最小值这类展示整理可以）。
2. **字段名兼容**：不同规则版本的摘要字段名可能不同（中文或英文），用 `base.pick(summary, 名1, 名2, ...)` 依次尝试；读不到就省略该项，不编造数字，不写死默认值。
3. **重点核对项（focus）**：`must_handle` 只用于确实会阻断下游的问题，写明“不处理将阻断：……”；其余用 `should_know`。已通过的模块不要制造新的待办。
4. **科学口径**：文字说明遵守根目录 AGENTS.md 第 4 节，例如查询失败不是 0 条、未匹配不是孤立节点、NA 不补 0、富集不等于通路激活、对接评分不跨受体比较药效。
5. **出错不拖垮页面**：`present()` 捕获展示函数的异常，降级为通用展示并提示；但不要依赖这一点掩盖问题，新增字段要有测试。
6. 新增或修改返回字段时，同步更新 `../api/AGENTS.md` 第 6 节，并通知前端。
