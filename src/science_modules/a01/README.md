# A01 三库科学来源模块

该目录保存从旧三库候选代码迁入的参数化解析、已有关系采集和候选计算。原生产版本 `src/components_multisource_flow.py` 保留原字节及 `A01.multisource.1` 行为。

调用方须先固定并验证来源文件SHA-256、药味与来源绑定。`herb_records`显式传入药味→工作簿；`batman_records`显式传入官方拼音条目→药味及可选PubChem快照凭据；`tcmsp_records`显式传入当前药味。

`build_candidate`接收这些来源记录、当前研究的TCMSP标准结果、同一HGNC映射对象/身份摘要，以及明确的三库药味覆盖清单。返回候选事实，不发布、不审批、不生成A03；身份未知时保留问题明细并阻断交接。已有研究的3条例外只能由旧绑定契约读取，新候选不默认省略未知关系。

依赖：Python≥3.11、openpyxl 3.1.5（独立科学环境中安装）。接口进程不导入该包，因此只用标准库仍可查看归档。来源和版本见本目录索引；完整接入范围见项目docs中的《A01三库代码与结果接入》。
