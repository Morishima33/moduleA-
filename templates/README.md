# 双报告模板固定规范

当前展示规范固定为`A07.double_report.24`，对应`A07.report.config.24`。用户于2026年10月15日明确要求固定当前模板并同步正式大纲。现行大纲为[首版项目指导大纲v1.3](../docs/ModuleA首版项目指导大纲_v1.3_目的导向流程图.docx)，v1.0—v1.2保留历史；本轮仅更新目的导向流程图及入口。

## 固定内容

专业版保留主要结论、关键数量、来源方法、交集与PPI、GO/KEGG、对接、研究线索、结果复核说明和参考文献，全部批注术语及参数解释统一在末尾附录。首页删除重复PPI名单，结构摘要只展示原始评分升序前十组。GO各类前十五表、KEGG两排名各前十表，图与图注在对应表前；既有GO各前八图和KEGG前十五图保留展示范围。

简略版正文目标约两页，另加与专业版同一套末尾术语附录；当前验证样稿共三页。页数随实际内容核查，不将样稿页数作为新病例固定事实。报告不单列“主要限制”章节，研究用途和实际范围仍如实表达。

热图保持完整中英标签、换行、同源原评分及完整同批色标；整幅图居中，左侧留边按标签量取。图内底部解释移入Word附录。所有计数、对象、通路与评分来自本次已核对数据，不把上一病例225组合或64标记固化为新研究预期。

## 固定实现与核对

程序化模板由`src/report_dispatch.py`按科学协议分派；第24版在`src/science_modules/a07/appendix_reports.py`、`appendix_documents.py`和`appendix_heatmap.py`，历史版本不删除。精确指纹见[A07.double_report.24.lock.json](A07.double_report.24.lock.json)，运行`Python 3.11+ tools/check_report_template.py`可只读核对所有固定文件。

清单固定模板渲染及直接排版依赖，不冻结研究输入、工作流状态或整个科学环境。模板规则变化新增版本号，不原地改写第24版。后续版本新增分派不自动修改历史模板指纹。

## 新疾病适配边界

当前第24版完整生成已验证的A06输入协议为`A06.trial.handoff.1`。其他科学协议保留原分派；新疾病达到A07前必须核对模板适配，不能静默改回旧版样式，也不能把严格结果改标为扩展试算来套用第24版。模板固定不代表新的协议适配已验证。

每项新研究独立建档，旧病例的预算、结构例外、身份例外、评分和审批不迁移。两份报告共用同一事实包，所有新增报告仍需用户独立复核。按成分/受体下拉定位，点击后才生成指定出图包；不预先制作全部包。

## 历史说明

第22版完成批注与中英显示，第23版精简结构前十、富集正文及对接分页，第24版统一末尾附录与图表顺序。旧版本按原协议复核与复算，原报告文件不覆盖。本目录保存规范与指纹，不另放一份与程序脱节的空白Word母版。
