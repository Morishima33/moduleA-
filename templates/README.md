# 双报告模板实施说明

旧模板参考副本在references/legacy_templates，原文件未修改。双报告采用程序化模板，经`src/report_dispatch.py`按来源协议分派；扩展A06结果当前进入`science_modules/a07/refined_reports.py`，模板为`A07.double_report.23`，第22版及更早代码保留。模板版本、同源事实与图件随每次修订写入`report_index.json`。本目录保存结构和文字边界说明，不另放一份会与代码脱节的Word母版。

第23版按最终模板截图调整：结构摘要只列原始评分从低到高前十组；第五章不重复列GO前三与KEGG前五文字，直接展示GO三类各前十五、KEGG两种排名各前十表。热图英文名称完整换行，两份报告共用；整理对接图表分页，保留纵横页方向。删除独立“主要限制”章节，后续章节连续编号；用途与方法中的事实边界保持。完整矩阵仍保留225格，旧报告不回写。参见[本轮模板说明](../docs/最终报告模板精简_v23_20261015.md)。

第22版落实用户附加Word的16条批注及已确认方案；专业版GO/KEGG各按摘要→表→图，增加统计显著性/Count首位命中图；简略版共用核心事实，完整组合清单与两个大通路图放专业版。内部编号仅在机器索引中保留。详见[已确认批注清单](../docs/报告批注与精确选择实施清单_v22_20261014.md)。

## 详细版

复用六份旧模板的章节、方法与结果表达、图表结构，按指导大纲更新OTP并集、PPI范围及两轮用途、双成分排序、BH p.adjust、背景、快速对接方法和结论。删除旧病例固定数字、三味药固定句式、无依据的成功断言。模板说明不得把未执行步骤写成已完成。

## 简略版

目标约两页：对象和版本、主要结论、关键数量、分子对接原始评分热图、最多三条经复核线索、下一步核验建议、完成情况与限制、参考文献及详细报告索引。结论允许支持有限或资料不足；不生成未经验证的关联总分或疗效概率。

热图行是成分，列是蛋白，单位kcal/mol。评分来自核验通过的实际计算；缺失不填零。图色表示数值，不表示有效/无效等级。不凭不同靶点间最低分宣称疗效最强。

## 共用规则

两版报告、网页和图表共用审核后的标准结果与结论；数值可溯源。改模板另记版本，不覆盖旧报告。未运行、合法空结果和资料不足使用各自措辞，不靠固定成功段落填充。

## 当前实现

- 专业详细版包含研究对象与用途、关键数量、模块方法与结果、PPI和富集摘要、对接矩阵与热图、研究线索、结果复核说明及参考文献。第23版不再单列“主要限制”章节，方法与用途中的事实范围保留。
- 临床简略版固定为约两页，突出共同结论、关键数量、热图、最多三条线索、限制和下一步建议。
- 两版从同一A07结构化结果生成；不分别手工抄写数量和结论。
- 任何重新生成都会创建新的`report_rev_*`目录；旧报告保留，研究索引只指向当前版本。
- 当前报告仍须人工复核共同结论，程序不自动批准A07。
